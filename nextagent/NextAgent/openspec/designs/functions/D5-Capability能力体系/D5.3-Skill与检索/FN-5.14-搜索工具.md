# FN-5.14 搜索工具

> 能力域 D5 Capability 能力体系 · 子域 [D5.3 Skill 与检索](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-5.8](../../../features/D5-Capability能力体系/D5.3-Skill与检索/F-5.8-工具渐进式加载.md) |
| spec | `tool-search-tool` |
| 接口 | 能力调用端口（工具搜索工具） |

## 描述

模型通过工具搜索工具发现当前请求内受治理的延迟 Tool 与 Skill 安全元数据；默认可见能力保持直接可用且不被重复搜索。

## 前置条件

- 请求正在执行。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 搜索关键词 | 是 | 工具或技能的搜索词 |

## 输出

匹配的工具和技能元数据列表。

## 处理过程

1. 系统在当前请求范围内搜索可用工具和技能元数据。
2. 返回匹配结果。

## 结果

- 正常：返回匹配结果。
- 无匹配：返回空列表。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 可量化阈值 | 无；搜索范围见描述 | 已定义 | 本特性 |
