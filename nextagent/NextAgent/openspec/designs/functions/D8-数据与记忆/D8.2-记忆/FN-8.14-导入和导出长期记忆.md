# FN-8.14 导入和导出长期记忆

> 能力域 D8 数据与记忆 · 子域 [D8.2 记忆](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 当前状态 | 稳定 |
| 覆盖特性 | [F-8.2](../../../features/D8-数据与记忆/D8.2-记忆/F-8.2-长期记忆.md) |
| 主规格 | [long-memory-import-export](../../../../specs/long-memory-import-export/spec.md) |
| 接口 | 长期记忆管理界面；既有个人记忆列表与批量新增 API |

## 描述

系统为长期记忆管理用户提供可预览、受容量约束且可安全恢复的 JSON 批量导入，以及本地化、公式安全的当前个人记忆筛选 CSV 导出。

## 前置条件

- 用户处于可信 Owner Scope、Agent Scope 和默认记忆实例的长期记忆管理界面。
- 导入文件由用户明确选择，导出由用户明确触发。

## 输入

- 导入：UTF-8 JSON 数组，或包含 `_instructions` 与 `memories` 的固定模板对象。
- 导出：当前“我的记忆”或“已归档”Tab，以及当前搜索、记忆类型、来源和更新方式筛选；当前页码不进入导出范围。

## 输出

- 导入产生待确认预览、容量与校验反馈、成功处理数和失败数，或结果未知状态。
- 导出产生当前个人记忆 Tab 完整筛选结果的本地化、公式安全 UTF-8 BOM CSV；失败时不输出不完整文件。

## 处理过程

1. 系统完整校验并预览导入内容，在用户确认前不写入记忆；预览项以紧凑标题行展示摘要、记忆类型、标签和置信度，并提供右上角小型删除按钮。
2. 预览期间读取 ACTIVE 与 ARCHIVED 的 `CONFIGURED` 总数之和作为已有个人设定记忆数，排除 `LEARNED` 等非个人设定记忆，显示上限 50、已有数和 `max(0, 50 - existing)` 的可导入数；该容量读取只用于反馈，不替代或阻断服务端最终 50 条容量和安全准入。
3. 每次文件成功解析生成新的随机导入批次标识；用户确认后以 JSON 契约版本、当前批次标识和原文件元素序号稳定派生的幂等键提交一个批次。删除前序元素不改变其余元素在当前批次中的键；重新选择字节完全相同或同名的文件建立新批次并使用不同幂等键，因此主动重选可再次新增；网络、5xx 或畸形成功响应保留原集合和当前批次供用户显式精确重试，明确 4xx 不进入结果未知状态。
4. 系统从当前个人记忆 Tab（“导出我的记忆”固定 ACTIVE、“导出归档的记忆”固定 ARCHIVED）的 offset 0 读取全部筛选分页，全部成功后生成本地化且公式安全的文件；共享记忆库不呈现个人导出操作。成功提示按当前 Tab 说明实际导出数量。

## 结果

- 合法导入只处理用户确认保留且通过服务端最终准入的记忆；同一 pending 批次内未知结果原样重试复用相同幂等键不重复写入，重新选择相同文件建立新批次可再次新增。
- 筛选导出不包含共享记忆或服务端权威字段，并阻止用户可控单元格作为公式、命令或超链接执行。
- 文件、容量、服务端或分页失败均产生明确反馈，不产生部分写入预览或不完整下载。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 单个导入文件大小 | 不超过 5 MiB/文件，包含边界；按用户选择的原始文件 bytes 计数 | `批量导入必须在不可信 JSON 边界完成前置校验` |
| 单次导入记忆数 | 1 至 50 条/文件，包含首尾边界；按顶层数组或 `memories` 元素计数 | `批量导入必须在不可信 JSON 边界完成前置校验` |
| 用户设定记忆总量 | ACTIVE 与 ARCHIVED 的 `CONFIGURED` 记忆合计不超过 50 条/可信 Owner Scope、Agent Scope 和默认记忆实例；客户端用于反馈，服务端最终裁决 | `上传后必须预览、删除并确认导入`、`确认导入必须调用批量新增接口` |
| 导入批次幂等范围 | 每次文件选择生成新批次 ID；同一 pending 批次内按原文件序号稳定，未知结果原样重试复用；重新选择相同文件建立新批次 | `确认导入必须调用批量新增接口`、`导入结果必须准确报告部分成功和中断进度` |
| 个人导入容量反馈 | ACTIVE 与 ARCHIVED 的 `CONFIGURED` 总数相加排除 `LEARNED`，显示上限 50、已有数和 `max(0, 50 - existing)`；服务端最终裁决 | `上传后必须预览、删除并确认导入` |
| 个人记忆导出呈现 | 我的/归档分别命名并显示实际数量成功提示，共享 Tab 不呈现个人导出操作 | `筛选导出必须安全读取当前个人记忆结果` |
| 个人记忆导出范围与安全格式 | 当前个人记忆 Tab 的完整筛选结果；UTF-8 BOM CSV，17 列，中英文投影，半角/全角 `= - + @` 及前导控制字符公式注入防护 | `筛选导出必须安全读取当前个人记忆结果` |
