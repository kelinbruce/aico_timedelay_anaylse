## 用户价值

用户可以从新会话或已有会话提交问题并立即获得可跟踪的请求/运行标识。网络重试不会复制同一业务请求，同一会话也不会出现多个并发运行破坏对话顺序。

## 主要用例

- 从便捷入口提交首个问题，由系统建立并绑定新会话。
- 在已有会话中提交后续问题，沿同一 Agent 与 Owner Scope 运行。
- 客户端因超时重试相同幂等请求，获得首次受理结果。
- 使用 model-only 请求显式禁用 Tool，而不改变 Agent 自有预算。

## 黑盒边界

- 请求通过运行时命令入口进入，前端不自行创造处理状态。
- 同一会话同一时间只允许一个活动请求，新请求需等当前请求结束。
- 身份和智能体归属只来自可信边界，请求体不得覆盖。
- request 可以用 `executionMode=model-only` 禁用 Tool，但不能携带或覆盖 Agent-owned Tool-call 数量预算。
- 每个请求只有一个权威终态。

## 适用质量属性

- 一致性：相同幂等键返回首次结果；每个请求只有一个终态。
- 隔离性：Agent Scope 与 Owner Scope 在受理时固化。
- 可诊断性：请求标识、运行标识和安全拒绝原因可用于端到端关联。
- 容量与并发：同会话 lane 串行化活动请求，避免无界并发修改同一会话事实。
