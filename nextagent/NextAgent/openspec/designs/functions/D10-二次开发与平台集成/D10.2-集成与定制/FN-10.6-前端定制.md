## 描述

系统提供 UI 定制契约、多宿主模式、结构化渲染和组件注入，并为 Process Detail 中的 PIU 定制视图提供“视觉折叠不重置、owner 移除才卸载”的浏览器生命周期。

## 前置条件

- 前端已配置。
- Process Detail PIU 已由受信的前端投影识别；只有用户已查看并完成首次挂载的 Detail 才可进入持续 render membership。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 定制配置 | 是 | UI 定制、布局、展示控制等 |
| Process Detail PIU 内容与 run scope | 否 | 流渲染 PIU 内容以及 `rootMessageId + displayRunId` 归属范围 |
| 扩展 Capability 业务名称 | 否 | AICOConfig 启动快照可包含 `capabilityBusinessNames`，每项为 `TOOL`、`AGENT`、`SKILL`、`WORKFLOW` 之一并提供 `zh-CN` 和/或 `en-US` 纯文本名称 |

## 输出

定制后的前端行为；合法名称配置可供过程标题使用，缺失、部分非法、重复或超量配置确定性降级，且不阻塞其他前端定制；已挂载 Process Detail PIU 在视觉折叠间保留交互状态，owner scope 移除后清理前端容器。

## 处理过程

1. 系统提供 UI 定制契约。
2. 支持多宿主模式、结构化渲染和组件注入。
3. 配置不热加载，经手写校验；local 与 immersive 在页面启动时一次性读取并校验 `sessionStorage["AICOConfig"]`，collaborative 通过 `loadAIAgent` 接收完整 payload 并完整替换当前配置。
4. `capabilityBusinessNames` 由专用逐项校验按数组顺序处理至多 1000 项，以规范化 `${kind}:${id}` 作为重复判定键；首个有效条目生效，后续重复条目告警跳过；单个语言非法时只删除该语言，两个语言均无效时删除整项。
5. Process Detail 中已挂载的 PIU 在条目、面板或 reduced-motion 折叠时只切换可见性和交互可达性，保留同一实例；未查看 PIU 不预挂载，非 PIU Detail 继续在折叠后卸载。
6. 条目或 `rootMessageId + displayRunId` scope 移除时，卸载 PIU Detail、阻止迟到 emit 并清空容器 DOM；不扩展未定义的 host `dispose`/`destroy` 契约。

## 结果

- 正常：前端定制生效。
- 名称配置：合法条目进入 `AICOConfig` snapshot，供过程标题按当前语言消费；缺失或非法条目确定性降级且不阻塞其他定制。
- PIU 恢复：重新展开同一 Process Detail 时恢复原交互实例，不因折叠重复初始化。
- PIU owner 移除：前端只清理自己拥有的异步回调和 DOM 容器；容器外资源仍由外部 PIU 管理。

## 规格

| 规格项 | 规格值 | Requirement source |
|---|---|---|
| 完整过程入口部署级开关 | `portalAbilityConfig.fullProcessEnabled=false` 时只隐藏“完整过程”按钮，保留 ProcessPanel 摘要和折叠过程条目；入口可见性与过程数据可还原性、`showThinkingChain !== false` 按 AND 组合 | `aico-display-control`：`Portal full-process gate controls full process entry` |
| Capability 业务名称配置范围 | 支持 `TOOL`、`AGENT`、`SKILL`、`WORKFLOW`，每项可提供 `zh-CN`、`en-US` 纯文本名称，最多 1000 项；`id` 为 1 至 128 个 Unicode code point，名称为 1 至 256 个 Unicode code point，不接受其他语言 key | `AICOConfig configuration type and field definitions`、`AICOConfig validation uses hand-written functions` |
| AICOConfig 宿主注入 | local 与 immersive 使用一次性 `sessionStorage` 启动快照，collaborative 使用完整 `loadAIAgent` payload；均不支持 hot update | `AICOConfig injection paths per host mode` |
| 结构化详情按 messageType 渲染 | `DETAIL`/`SUB_DETAIL`/`SUB_CONCLUSION` 按 `toolMessageType` 分段累积到 `structuredSegments`，复用 `AnswerSegment`/`AnswerSegments` 按 messageType 分发；`detail` 字符串只累积 TEXT，非 TEXT 不进 detail；稳定关联标识归并，无匹配 TITLE 时忽略不串位 | `agent-web-structured-message-rendering`：`Process Panel Entry Generation`、`Non-TEXT messageType content is rendered by structured renderer in process panel` |
| 结构化 workflow 默认展开 | 包含 TITLE/SUB_TITLE 结构化条目的 ProcessPanel 首次渲染已 settled 时默认展开，settled 不自动折叠；用户手动折叠仍生效；普通 settled 过程面板保持默认折叠 | `agent-web-process-panel`：`Structured workflow process presentation remains visible` |
| renderKnowledge 协作式 PIU handler | `renderKnowledge` 只在 `registerAIAgentPIU` 注册，独立 React root + `AppProviders`；列表项标题 `source`→`title`→`knowledge` 前 100 字符三级 fallback；点击打开 theme-aware Modal 用 `MarkdownContent` 解析；不修改 `prel.ts` | `agent-web-piu-knowledge-render`：`renderKnowledge capability is scoped to collaborative PIU only`、`PIU exposes renderKnowledge handler through attach`、`Knowledge source list item title resolution`、`Knowledge source list renders into container with independent React root`、`Knowledge source detail opens in theme-aware modal` |
