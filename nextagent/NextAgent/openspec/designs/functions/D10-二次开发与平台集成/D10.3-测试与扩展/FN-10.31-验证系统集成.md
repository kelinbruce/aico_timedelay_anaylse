## 描述

TestClaw 根据受版本控制的 122 个用例清单，对候选运行包和外部 package artifacts 独立执行系统集成与 E2E 流程，输出统一结论、逐条追踪和安全 evidence refs。本 Function 是 TestClaw 独立系统集成验证的唯一执行 owner，不复用源码测试结果作为候选包 verdict。

## 前置条件

- 提供候选运行包根（`NEXTAGENT_PACKAGE_ROOT`，缺省 `tests/TESTClaw/target`）。
- 提供外部 packages 根（`NEXTAGENT_EXTERNAL_PACKAGES_ROOT`，无缺省），含 remote package public artifacts 及 `@nextagent/agent-web-test-hosts` 的公开 hosting export。
- TestClaw 自有 fixtures 和场景要求的本机浏览器能力可用；输入缺失形成显式非通过结果，不回退源码。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 122 用例清单 | 是 | 受版本控制的 `case-manifest.ts`，连续 `TC-SI-001..122` |
| 候选运行包 | 是 | 本地候选进程、frontend artifact、候选文件系统 |
| 外部 package artifacts | 是 | remote deployment/gateway public exports、SkillHub、test-hosts hosting export |
| 隔离执行配置 | 是 | 隔离 runId、端口、临时持久化根、restricted diagnostic root、evidence root |

## 输出

包含总结果、分层结果（`INTEGRATION`/`E2E`）、122 个逐用例结果、双向追踪和安全 evidence refs 的 machine-readable `report.json`（`checkId=system-integration`）。

## 处理过程

1. 创建隔离 `runId`、temp/restricted-diagnostic/evidence roots 和进程登记表。
2. 校验 122 manifest、唯一 `sourceCaseRef → caseId → executionRef` 映射和两个输入根；缺号、重号、映射不唯一或共享 `executionRef` 在启动候选进程前失败。
3. 启动共享候选/loopback fixtures；共享仅降低启动成本，不共享 case verdict。
4. 在固定进程级 deadline 内只执行 manifest 引用的 Vitest/Playwright 文件；Vitest 固定最多两个 file workers，框架 stdout/stderr 只进入有大小上限的内部捕获缓冲。
5. 把 reporter 输出按 `executionRef` 归一为恰好 122 个结果；无结果记 `MISSING`，skip/todo 记 `FAILED`；每个 `PASSED` 结果必须解析到本次 output root 下唯一且内容匹配的 `cases/<caseId>.json`。
6. 扫描 TestClaw 将要导出的 summary stdout、report 和逐 case evidence，命中禁止内容时覆盖对应用例为 `FAILED`；候选本地 operational log 只在 restricted diagnostic root 原位接受其所属稳定日志契约的断言，不进入通用 evidence 扫描输入。
7. 按 `FAILED > TIMEOUT > UNAVAILABLE > MISSING > PASSED` 归并层级和总状态；`layers` 固定为 `{INTEGRATION: result, E2E: result}`，原子写入 report。
8. 在 `finally` 停止本次进程、关闭监听器并删除 restricted diagnostic root 与其他非 evidence 临时根。

## 结果

- 通过：3 个 `INTEGRATION` 和 119 个 `E2E` 用例全部 `PASSED` 且 evidence 安全，命令返回零退出码。
- 非通过：任一用例缺失、不可用、超时、失败、追踪非法或 evidence 泄漏时，总 `status` 按固定优先级确定为非通过，命令返回非零退出码。
