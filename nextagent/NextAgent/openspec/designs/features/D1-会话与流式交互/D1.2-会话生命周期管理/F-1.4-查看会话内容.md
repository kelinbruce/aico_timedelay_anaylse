## 描述

用户可以翻页查看会话的历史消息，通过锚点定位到特定消息，并以安全、语义一致且适配宽窄视口的 Markdown 形式阅读已完成的普通 assistant 正文；会话页面在三种宿主中使用统一 Header 和 `contained` 内容边界，同时保留既有消息 viewport 与 overlay composer 语义。

## 边界

- 默认返回最近可见消息窗口，历史消息需翻页加载。
- 查看范围受用户归属和智能体归属限制。
- 前端只拥有消息正文的安全投影和响应式布局，不改变消息、stream、request lifecycle 或持久化事实。
- 原始不可信 HTML 不因任务列表展示而获得交互或执行能力。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
