## 用户价值

Agent 可以从当前 Agent 获准的逻辑知识索引中检索可信片段，用于回答网络运维、诊断和产品知识问题；用户能够区分“确实零命中”“获得部分可用证据”和“检索系统失败”，并在聊天过程面板确认召回数量与每条结果的来源名称。

## 主要用例

- 使用默认逻辑索引检索与当前任务相关的知识片段。
- 显式选择已授权逻辑索引，并以受限 `topK` 获取结果。
- 处理零命中、索引缺失/未就绪、provider 瞬态失败或部分检索完成。
- 依据返回片段继续推理，同时识别尚未完成的声明检索范围。

## 黑盒边界

- 检索只依赖公共检索网关。
- 本地语料按可信工作区范围构建。
- 合法零命中保持成功；只有已有可独立使用 chunks 且其余声明检索范围明确未完成时才返回降级，无 chunks 的失败保持真实 category。
- 调用输入不能选择 Owner/Agent Scope、credential 或底层 provider；这些只来自可信 composition。
- provider diagnostics、query、路径和凭据不进入用户结果或低基数观测。

## 适用质量属性

- 相关性与可解释性：返回片段和完成状态足以区分完整、空和部分结果。
- 安全性：检索始终按 Agent/Owner Scope 与索引治理隔离。
- 容量：输入、结果和单次公共 Capability envelope 都有稳定上限。
- 可靠性：幂等检索只在明确瞬态门禁内 retry，取消和未知异常不被掩盖。
