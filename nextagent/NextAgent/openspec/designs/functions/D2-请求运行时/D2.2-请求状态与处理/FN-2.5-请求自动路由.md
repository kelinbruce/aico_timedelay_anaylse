# FN-2.5 请求自动路由

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-2.5](../../../features/D2-请求运行时/D2.2-请求状态与处理/F-2.5-请求自动路由.md) |
| spec | `agent-routing-core`、`routing-evidence-and-fallback` |
| 接口 | 系统内部，请求受理后触发 |

## 描述

系统根据请求内容和装配事实自动决定处理方式，如确定性流程、模型驱动循环、澄清、拒答或人工接管。

## 前置条件

- 用户已登录。
- 请求已被受理。

## 输入

请求内容 + 智能体装配事实（只消费可信事实）。

## 输出

路由决策：确定性流程、模型驱动循环、澄清、拒答或人工接管。

## 处理过程

1. 请求受理后，系统执行路由策略决策。
2. 路由只消费可信事实，不信任客户端元数据或模型输出。
3. 选择处理方式并记录路由证据。
4. 若路由依赖不可用，安全失败。

## 结果

- 正常：路由到合适的处理方式。
- 依赖不可用：安全失败。
