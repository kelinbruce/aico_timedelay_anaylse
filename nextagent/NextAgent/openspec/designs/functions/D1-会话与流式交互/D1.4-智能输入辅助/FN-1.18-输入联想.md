# FN-1.18 输入联想

> 能力域 D1 会话与流式交互 · 子域 [D1.4 智能输入辅助](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.9](../../../features/D1-会话与流式交互/D1.4-智能输入辅助/F-1.9-智能问题推荐.md) |
| 主规格 | `question-association-api` |
| 遗留规格 | `question-association-ui` |
| 接口 | `GET /api/v1/question-association` |

## 描述

用户主动编辑消息输入框时，系统根据非空普通文本实时联想匹配的问题；单次粘贴和上下键回看已提交消息本身不触发输入联想，编辑回看的文本后恢复联想。

## 前置条件

- 用户已登录。
- 用户正在主动编辑 trim 后非空、首字符不是 `/` 的文本。
- 单次粘贴写入和仅回看已提交消息不满足联想触发条件。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| keyword | 是 | 输入关键词 |

## 输出

```json
{
  "questions": [
    { "text": "切换失败的原因有哪些", "source": "pinned" },
    { "text": "如何优化邻区配置", "source": "high-frequency" }
  ]
}
```

## 处理过程

1. 系统先判定输入文本来源；单次粘贴和历史回看不发起联想，历史回看期间取消该输入框的待处理查询。
2. 用户主动编辑普通文本时，系统在停止编辑 300ms 后发起查询。
3. 系统按关键词做大小写不敏感的子串匹配，并按收藏、高频、静态三层排序。
4. 各层按容量级联填充，总数上限 20 条，每条结果带来源标签。
5. 系统只在结果返回时输入框仍保持焦点的情况下展示非空结果，并保持联想面板与斜杠命令面板互斥。

## 结果

- 正常：主动编辑普通文本且结果返回时输入框仍保持焦点，则展示匹配结果。
- 无匹配：返回空列表。
- 空关键词或斜杠命令：不触发联想。
- 单次粘贴或历史回看：不查询或展示联想；编辑回看的文本后恢复联想。
- 查询返回前输入框失焦：迟到结果不打开联想面板。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 结果上限 | 每次查询最多 20 条 | `question-association-api`：`联想查询 API 端点` |
| 来源与优先级 | `pinned` → `high-frequency` → `static` | `question-association-api`：`联想结果来源标签`、`三层来源加载与排序` |
| 匹配与去重 | 大小写不敏感的子串匹配；重复问题保留最高优先级来源 | `question-association-api`：`关键词模糊匹配`、`去重` |
| 触发来源 | 仅主动编辑 trim 后非空且首字符不是 `/` 的文本触发联想；单次粘贴和上下键历史回看不触发，编辑回看文本后恢复触发 | `question-association-api`：`联想面板触发规则` |
