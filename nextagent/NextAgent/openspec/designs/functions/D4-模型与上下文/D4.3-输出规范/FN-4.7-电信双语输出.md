# FN-4.7 电信双语输出

> 能力域 D4 模型与上下文 · 子域 [D4.3 输出规范](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-4.6](../../../features/D4-模型与上下文/D4.3-输出规范/F-4.6-电信双语输出.md) |
| spec | `telecom-bilingual-output` |
| 接口 | 系统内部，提示词规则 |

## 描述

系统通过提示词规则让模型跟随用户输入语言，对电信术语保留原始英文形式。

## 前置条件

- 请求已进入提示词装配阶段。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 用户输入语言 | 是 | 用户实际输入的语言 |

## 输出

跟随用户语言的模型输出，电信术语保留英文。

## 处理过程

1. 系统识别用户输入语言。
2. 应用双语规则，模型默认跟随用户语言。
3. 对电信术语保留原始英文形式。

## 结果

- 正常：输出跟随用户语言，术语保留英文。

|---|---|---|---|
