# FN-11.1 恢复运行状态

> 能力域 D11 可靠性与韧性 · 子域 [D11.1 恢复与幂等](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 当前状态 | 稳定 |
| 覆盖特性 | [F-11.1](../../../features/D11-可靠性与韧性/D11.1-恢复与幂等/F-11.1-重启恢复运行.md) |
| 主规格 | `local-runtime-recovery` |
| 遗留规格 | `runtime-recovery-idempotency-guard` |
| 接口 | 系统内部，启动恢复 |

## 描述

系统重启后根据持久化事实恢复运行状态与同一 `RequestRun` 的 logical Agent turn coordinate，无法安全恢复时显式失败。

## 前置条件

- 系统重启。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 持久化事实 | 是 | 排队、执行中、终态待定、终态等 |

## 输出

恢复的运行状态。

## 处理过程

1. 系统启动时扫描持久化事实。
2. 按状态分类：排队重建调度、执行中重建上下文、终态待定等待、终态幂等。
3. 校验 checkpoint 与 `RequestContext.agentTurnIndex`、run、timeline 和 message facts 一致；normal/finalizing 由该坐标和 accepted `maxTurns` 推导。
4. 非幂等能力调用前检查幂等声明，默认非幂等。
5. pause、resume 与 crash recovery 保持原 turn，不能重置 `maxTurns` 或重复 finalizing；无法安全证明时显式失败。

## 结果

- 正常：运行状态恢复完成。
- 无法恢复：显式失败，不伪装成功。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| Agent 轮次恢复连续性 | 同一 `RequestRun` 恢复后继续原 logical Agent turn；已进入 finalizing 的 run 不回到 normal turn，finalizing 最多一次 | `local-runtime-recovery`：`Executing recovery 必须从 checkpoint 和 messages 重建 RequestContext` |
| 非幂等重复副作用容忍 | 0；缺少安全重放证据时 fail closed | `runtime-recovery-idempotency-guard`：非幂等恢复约束 |
