# FN-10.11 开发工作台

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-10.11](../../../features/D10-二次开发与平台集成/D10.3-测试与扩展/F-10.11-开发工作台.md) |
| 主规格 | `dev-agent-workbench` |
| 接口 | local 模式的只读工作台页面与查询接口 |

## 描述

系统在 local 开发模式提供只读工作台，用于查看当前 Agent 配置、模型清单、默认模型以及请求运行过程的安全诊断投影。

## 前置条件

- local runtime 已启用工作台；
- 当前 Agent 与开发者身份已经可信确定。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 当前 Agent | 是 | 由可信运行环境决定，不接受客户端覆盖 |
| 诊断范围 | 是 | 当前 Agent、会话或请求运行范围 |

## 输出

安全、只读且有界的 Agent 配置与运行证据。模型视图返回可信配置中的 `modelIds/defaultModelId`，不得从运行事件猜测默认模型。

## 处理过程

1. 工作台确认当前可信 Agent、开发者身份和允许查询的范围。
2. 配置视图展示 Agent 版本、能力引用、`modelIds` 与 `defaultModelId`。
3. 运行视图只展示授权范围内的活动诊断证据，并对并发轮转和超限读取做安全处理。
4. 页面只展示已批准的安全字段，不暴露 credential、prompt、模型输出或 raw provider error。

## 结果

- 正常：返回与当前 Agent 配置和活动运行证据一致的只读诊断结果；
- 降级：工作台不可用不阻塞 local app 主服务启动；
- 拒绝：越权范围、归档诊断文件或非法输入不进入投影。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 可用范围 | 仅 local 开发运行时；查询只读且复用已认证 Owner Scope 和可信 Agent 范围 | `dev-agent-workbench`：`Workbench reuses the authenticated Owner Scope and trusted Agent graph`、`Workbench is non-realtime and read-only` |
| 运行视图 | 只展示与目标运行匹配的冻结配置和已有执行事实；缺失时不回退到当前配置 | `dev-agent-workbench`：`Workbench exposes a reconstructed run effective view` |
| 上下文页签 | 恰好为“对话”“详情”“运行配置”“日志”四个，不另设 Agent 页签 | `dev-agent-workbench`：`Workbench uses four non-duplicated context tabs` |
| 安全边界 | 诊断内容有界，不新增 raw prompt、模型输出、工具参数/结果、provider raw body、credential、token、附件内容或路径 | `dev-agent-workbench`：`Workbench exposes a reconstructed run effective view`、`Workbench exposes bounded log evidence for request/run debugging` |
