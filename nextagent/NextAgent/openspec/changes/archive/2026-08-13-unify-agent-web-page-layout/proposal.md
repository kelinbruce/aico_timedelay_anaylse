## Why

Agent Web 的会话、定时任务和收藏页面目前分别实现页面骨架：标题栏高度、标题字重、操作区排列、内容宽度和滚动容器均不一致。用户在这些主内容页面之间切换时会看到明显的视觉跳变；窄视口下各页面也缺少统一的单行标题与操作区布局规则。

更重要的是，会话页面已经形成完整的滚动 viewport、浮动 footer 安全区和跟随底部行为，而其他页面继续复制页面结构容易把“谁提供滚动容器”和“谁决定滚动策略”混为一体。Agent Web 页面开发者需要一个可复用的页面布局契约，使新增页面能够复用一致的 Header、Content 和 Footer 骨架，同时让各业务页面继续拥有自己的滚动策略。

## 目标与非目标（Goals / Non-Goals）

**目标：**

- 用户在会话、定时任务和收藏页面之间切换时，可以依赖一致的页面标题栏高度、字体、内边距、操作区排列和主题表现。
- 页面标题栏在窄视口下保持单行并截断标题；页面操作区域由目标页面声明，统一布局原样呈现且不重排、隐藏或转换页面操作。
- 页面内容可明确选择最大宽度居中的 `contained` 模式或扣除统一水平安全内边距后占满可用宽度的 `fluid` 模式。
- 页面只出现由目标页面声明的纵向滚动区域；会话跟随底部、历史锚点和分页行为保持不变，定时任务由页面内容区滚动，收藏继续仅在展开内容超出可用高度时滚动收藏内容区。
- Agent Web 页面开发者能够复用同一页面布局模板提供 Header、Content 和可选的 docked Footer，无需为每个新增页面重新实现页面骨架。
- Local、Immersive 和 Collaborative/PIU 宿主中复用的页面保持同形布局和相同滚动边界。

**非目标：**

- 不改变会话的跟随底部、用户滚动意图、历史分页、锚点定位、浮动置底入口或动态 footer 安全区语义。
- 不把会话 overlay composer 改为通用 docked Footer；会话专用 footer 仍保持覆盖式布局。
- 不改变定时任务、收藏、会话的业务数据、API、route、持久化、Owner Scope、Agent Scope 或权限边界。
- 不在本 change 中迁移记忆管理、投诉历史、最近历史或自定义扩展页面。
- 不允许任意页面内容接管共享标题栏的结构和视觉样式；返回入口只支持模板拥有样式的结构化返回操作。
- 不由统一布局决定页面操作的数量、优先级、按钮或菜单形态及响应式收纳策略。

## What Changes

- 新增 Agent Web 页面布局黑盒契约，统一定义 Header、Content、可选 docked Footer、主题、页面操作区域位置、内容宽度模式和滚动区域的可观察结果。
- 会话、定时任务和收藏页面采用该统一布局契约：Header 高度为 `48px`，水平内边距为 `16px`；标题字号为 `16px`、字重为 `500`、行高为 `28px`，且标题栏不显示底部分隔线、阴影或独立重复绘制的页面背景渐变。
- 统一布局提供 `contained` 和 `fluid` 两种内容宽度结果：`contained` 在 `1080px` 最大宽度内居中，`fluid` 在扣除左右各 `16px` 水平安全内边距后占满可用宽度。
- 会话、定时任务和收藏页面均不声明返回操作，标题从 Header 左侧内容起始位置展示；页面退出、路由切换或扩展容器关闭继续由各宿主自己的导航入口决定。
- 会话页面继续使用覆盖式 composer footer、动态 bottom safe area 和既有会话滚动策略；定时任务使用统一布局的内容滚动区域；收藏保留收藏内容区域的展开滚动与全部收起无滚动条行为。
- 窄视口下，页面标题保持单行并截断；目标页面继续拥有其操作内容和响应式展示策略，统一布局不生成“更多”入口。

## Feature 影响（Features）

### 修改的 Feature

- `F-1.4 查看会话内容`：增加统一 Agent Web 页面布局这一共享 Function，使会话页面获得一致的 Header 与 `contained` 内容边界，同时保持既有消息 viewport 和 overlay composer 语义。
- `F-1.7 标注对话`：增加统一 Agent Web 页面布局这一共享 Function，使收藏页面获得一致的 Header、`fluid` 内容边界和单一收藏内容滚动区域。
- `F-10.9 Cron 工具`：增加统一 Agent Web 页面布局这一共享 Function，使定时任务页面获得一致的 Header、`contained` 内容边界和 Content 滚动区域。

## Function 影响（OpenSpec Capabilities）

### 新增 Function

- `FN-10.35 呈现 Agent Web 页面布局` → `specs/agent-web-page-layout/spec.md`
  - 功能边界：用户打开采用统一布局的 Agent Web 主内容页面时，系统以一致的标题栏、页面声明的操作区域、内容宽度、可选 docked Footer 和单一纵向滚动边界呈现页面；首批适用页面为会话、定时任务和收藏。
  - 覆盖特性：`F-1.4 查看会话内容`、`F-1.7 标注对话`、`F-10.9 Cron 工具`。
  - 系统质量属性：可维护性、可测试性。
  - 迁移说明：`agent-web-right-pane-styles` 中被触及的 `右侧布局宽度` 原子迁入该主规格；来源 spec 的其他 Requirements 原位保留。

### 修改的 Function

- `FN-1.13 查看收藏列表` → `specs/favorite-turn-list/spec.md`
  - 功能边界：收藏页面移除独立定义的标题栏视觉尺寸和页内返回入口，改为遵循统一 Agent Web 页面布局契约；宿主导航、过滤、分组、分页、展开和取消收藏行为保持不变。
  - 系统质量属性：可测试性。
  - 映射说明：`favorite-turn-list` 继续作为 canonical spec；本 change 只修改其收藏主内容 Requirement 中的标题栏归属和可观察结果。

## 影响范围（Impact）

- 用户会看到会话、定时任务和收藏页面的 Header、内容边界和滚动条位置统一；收藏 Header 高度和标题字重会发生可见变化。
- Agent Web 页面开发者新增页面时可复用统一页面布局模板，并需要显式选择内容宽度和滚动归属。
- 受影响实现集中在 Agent Web 页面布局、会话布局适配、定时任务页面、收藏页面及三个宿主的页面投影；公共 Web API、后端 workspace、配置和持久化均不变。
- 需要更新布局组件、页面组件、样式、组件测试和三个宿主的浏览器验收；不新增运行时依赖。
