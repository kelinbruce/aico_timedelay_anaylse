# FN-6.4 风险评估

> 能力域 D6 安全与治理 · 子域 [D6.2 执行与风险治理](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-6.4](../../../features/D6-安全与治理/D6.2-执行与风险治理/F-6.4-风险策略.md) |
| spec | `risk-policy-enforcement` |
| 接口 | 系统内部，风险策略服务 |

## 描述

在高风险操作前评估风险，输出允许、拒绝、需授权、降级或策略失败。

## 前置条件

- 高风险操作待执行。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 操作信息 | 是 | 待执行的操作 |
| 安全摘要 | 是 | 可信安全摘要 |

## 输出

风险决策：允许、拒绝、需授权、降级或策略失败。

## 处理过程

1. 系统只消费可信安全摘要评估风险。
2. 输出风险决策。
3. 留下安全证据。

## 结果

- 允许：操作继续。
- 拒绝：操作被阻止。
- 需授权：转为请求用户授权。
- 降级：操作降级执行。
- 策略失败：安全失败。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 风险策略执行超时 | 1,000 ms | 建议评审值 | 建议补充 |
| 高风险确认阈值 | 风险等级为高或严重 | 建议评审值 | 建议补充 |
