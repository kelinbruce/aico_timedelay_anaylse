# FN-1.12 标注对话

> 能力域 D1 会话与流式交互 · 子域 [D1.3 对话标注与分享](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.7](../../../features/D1-会话与流式交互/D1.3-对话标注与分享/F-1.7-标注对话.md) |
| 主规格 | `conversation-annotation-controls` |
| 遗留规格 | `conversation-annotation` |
| 接口 | `POST /api/v1/sessions/:sessionId/runs/:runId/annotations` |

## 描述

对已完成的请求运行进行点赞、点踩、收藏或评论，可重复更新；回答收藏按单用户共享 100 条上限，净新增超限时安全失败并回滚浏览器乐观状态。`agent-web` 在每轮问答的助手回复操作行中提供复制、点赞、点踩、收藏和重新生成控件；点赞和点踩互斥，收藏独立；用户操作时立即投影目标状态，写入成功后按当前语言展示与本次操作一致的成功提示，写入失败回滚并显示安全错误反馈（不展示成功提示）；会话打开时按 `requestRunId` 恢复标注状态。

## 前置条件

- 用户已登录。
- 目标会话和运行属于当前用户和智能体。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| sessionId | 是 | 会话 ID |
| runId | 是 | 被标注的请求运行 ID |
| sentiment | 否 | 评价方向：点赞、点踩或空 |
| isFavorited | 否 | 是否收藏 |
| comment | 否 | 评论内容，最长 1000 字符 |

至少提供评价、收藏、评论其一。全部清空时物理删除标注记录。

## 输出

```json
{
  "annotationId": "ann_1",
  "sessionId": "sess_123",
  "requestRunId": "run_1",
  "sentiment": "UP",
  "isFavorited": true,
  "comment": "很有帮助",
  "createdAt": 1719878400000
}
```

## 处理过程

1. 校验会话和运行归属。
2. 更新或创建标注记录。
3. 若评价为空且未收藏且无评论，物理删除该标注记录。

## 结果

- 正常：标注更新成功，返回标注记录。
- 全部清空：物理删除，返回空状态。
- 未提供任何字段：安全失败。
- 权限不足：安全拒绝。
- 回答收藏数量达到单用户 100 条上限：安全拒绝并提示用户先取消部分收藏。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 评论长度 | 最长 1000 字符 | 已定义 | `conversation-annotation` |
| 回答收藏上限 | 单用户 100 条，跨 agent 共享；仅净新增触发，取消后释放 | 已定义 | `conversation-annotation` |
| 标注控件展示 | terminal 回复操作行按复制、点赞、点踩、收藏、重新生成顺序常驻；点赞/点踩互斥，收藏独立；写入失败回滚；会话打开按 `requestRunId` 恢复 | 稳定 | `conversation-annotation-controls`：`前端对话标注控制` |
