## 用户价值

Agent 可以在沙箱边界内执行受治理的命令和 Python 脚本，获得忠实的进程完成事实、安全输出和可纠正参数诊断，而不直接取得宿主进程权限。

## 主要用例

- 执行单条或受支持组合的 Bash 命令并检查 exit code、stdout/stderr。
- 执行通过代码 guard 的 Python 脚本处理运维数据。
- 修正 tokenization、quoted syntax、控制字符或脚本安全策略违规。
- 在 timeout、取消、sandbox unavailable 或 policy deny 时获得明确安全结果。

## 黑盒边界

- 命令执行经沙箱网关，默认拒绝。
- 命令权威下沉到沙箱策略，工具只负责分词和路由。
- 可纠正命令格式错误一次返回全部安全 violations；Bash 正常完成的非零退出与零退出同为结构化成功，不因 stdout/stderr 是否为空改变状态。
- Python guard、执行边界缺失、无效 sandbox response、timeout 与取消使用统一安全语义，非幂等 timeout 不自动重放。
- 命令、脚本、raw guard/provider error、sandbox path 和凭据不进入产品日志或安全错误。

## 适用质量属性

- 安全性：动态执行始终经过 sandbox gateway 和真实 policy/authorization。
- 结果保真：正常 non-zero completion 不被误报为失败或降级。
- 可恢复性：可修改输入错误给出完整 violations；非幂等结果不被自动重放。
- 可诊断性：timeout、取消、policy、dependency 和 internal failure 保持可区分。
