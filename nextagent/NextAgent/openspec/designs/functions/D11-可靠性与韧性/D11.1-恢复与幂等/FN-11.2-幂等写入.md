# FN-11.2 幂等写入

> 能力域 D11 可靠性与韧性 · 子域 [D11.1 恢复与幂等](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-11.2](../../../features/D11-可靠性与韧性/D11.1-恢复与幂等/F-11.2-幂等写入.md) |
| spec | `idempotency-contract`、`ts-web-command-idempotency` |
| 接口 | 系统内部，幂等写入 |

## 描述

系统对重复操作保持幂等，相同幂等键返回首次结果，不产生重复副作用。

## 前置条件

- 操作携带非空幂等键。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 操作 | 是 | 待执行的操作 |
| 幂等键 | 是 | 非空幂等键 |

## 输出

首次执行结果。

## 处理过程

1. 系统检查幂等键。
2. 重复键返回首次结果，不产生重复副作用。
3. 终态提交幂等，重复提交返回首次终态。
4. 复合操作在单一事务内完成。

## 结果

- 正常：操作执行成功。
- 重复：返回首次结果，不重复副作用。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 生成的幂等键最大长度 | 256 字符；超出时以 `toolCallId` 拼接值的 sha256 截断摘要塌缩，且相同输入始终产出相同 key | `idempotency-contract`：`生成的幂等键必须符合下游长度上限` |
| 非幂等重复副作用容忍次数 | 0 | 已定义 | 安全红线 |
| 终态不一致容忍次数 | 0 | 已定义 | 安全红线 |
| 每个复合写入事务数 | 1 | 已定义 | 架构约束 |
