# FN-1.17 查看高频问题

| 项 | 值 |
|---|---|

| spec | `frequent-question-api`、`user-question-activity` |
| 接口 | `GET /api/v1/frequent-questions` |

## 描述

查看基于用户行为动态排序的常用问题，系统按固定、收藏、高频、静态四层合并排序。

## 前置条件

- 用户已登录。

## 输入

无。

## 输出

```json
{
  "questions": [
    { "text": "分析小区掉话率升高原因", "source": "fixed" },
    { "text": "切换失败的原因有哪些", "source": "pinned" }
  ]
}
```

## 处理过程

1. 系统合并四层来源：固定问题、收藏问题、高频问题、静态问题。
2. 按层级排序，空列表时由前端回退到内置默认问题。
3. 用户每次提交请求时自动增长提问频率，不影响主流程；安全护栏拦截的 submit/edit（`guardBlockRefusal` 存在）不记录问题活动、不增长频率，cancel/retry 也不增长频率。

## 结果

- 正常：返回动态排序的问题列表。
- 无行为数据：返回固定和静态问题。
