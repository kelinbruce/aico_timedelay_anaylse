# FN-1.3 刷新页面后恢复未完成任务

> 能力域 D1 会话与流式交互 · 子域 [D1.1 流式交互与恢复](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.2](../../../features/D1-会话与流式交互/D1.1-流式交互与恢复/F-1.2-断线重连恢复.md) |
| spec | `ts-stream-resume-replay` |
| 接口 | SSE/WS 携带未完成任务坐标 + `lastSeenSequence=0` |

## 描述

用户刷新页面、新开标签页或更换设备打开有未完成任务的会话时，系统先加载历史对话，再从任务开头恢复推送未完成任务的内容。

## 前置条件

- 用户已登录。
- 目标会话已存在且属于当前用户。
- 会话存在未结束的未完成任务。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| sessionId | 是 | 会话 ID |
| requestId | 是 | 未完成任务的请求标识 |
| runId | 是 | 未完成任务的运行标识 |
| lastSeenSequence | 是 | 传 0，从任务开头补充 |

## 输出

先加载历史对话，再从未完成任务开头补充推送，补充后接续实时推送。

## 处理过程

1. 先加载历史对话作为已提交历史。
2. 若存在非终态未完成任务，按请求标识与运行标识定位，从任务开头（游标 0）补充推送。
3. 补充完成后接续实时推送。
4. 未完成任务的恢复按请求标识与运行标识定位，不依赖游标猜测。
5. 接续后执行一次合并，避免重复或遗漏。
6. 若恢复失败，明确提示用户处于断开或降级状态，不伪装成功。

## 结果

- 正常：加载历史后恢复未完成任务内容，接续实时推送。
- 无未完成任务：仅加载历史后只看新消息。
- 恢复失败：显式提示，不伪装成功。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| replay buffer 大小 | 1,000 个事件/运行 | 建议评审值 | 建议补充 |
| 冷启动恢复时延 | <= 3,000 ms | 建议评审值 | 建议补充 |
