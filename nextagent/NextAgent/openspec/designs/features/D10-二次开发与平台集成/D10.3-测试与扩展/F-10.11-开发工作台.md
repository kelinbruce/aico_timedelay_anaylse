## 描述

local 开发工作台以只读、安全且有界的方式展示当前 Agent 配置与请求执行证据，帮助开发者定位装配和运行问题。

## 边界

- 工作台只展示当前可信 Agent 范围内的配置和诊断事实；
- 模型清单与默认模型来自当前有效配置，不从运行事件推断；
- 工作台不可用时不影响主服务和请求处理；
- 不暴露 credential、prompt、模型输出、raw provider error 或归档日志内容。

## 用户可依赖的质量保证

- 工作台保持只读、范围受限，并能安全处理日志轮转和读取上限。
