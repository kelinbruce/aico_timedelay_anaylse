# NextAgent 对外特性介绍

NextAgent 是面向电信网络运维场景的 TypeScript 智能体后端框架，目标不是提供一个单点聊天工具，而是把大模型、网络知识、受控工具、人员确认、执行审计和平台集成放进同一条可治理、可验证、可交付的智能体主路径。它适用于网络故障诊断、巡检分析、配置核查、知识问答、运维报告生成以及行业智能体二次开发。

## 核心能力特性

### 1. 面向长任务的可信运行内核

NextAgent 采用异步事件驱动架构，围绕网络运维中的长时间诊断、巡检、报告生成等任务设计。框架通过 RequestRun、timeline、checkpoint、claim/fencing 和终态提交机制记录运行事实，支持长任务接续、安全终止和故障恢复。

### 2. 过程透明的流式交互体验

平台支持 SSE / WebSocket 两类流式通道，并保持一致的事件语义。用户可以看到请求受理、执行进展、工具调用、等待确认、降级、拒绝和最终结果，避免传统 AI 对话中的黑盒等待和重复提交。

### 3. 统一 Capability 能力体系

Tool、Skill、Agent 三类能力统一进入 Capability Catalog 管理。能力需要经过发现、描述、可用性判断、Agent 绑定和调用治理后才能被模型使用，避免“发现即授权”。内置能力可覆盖文件读写、检索、命令执行、Python、RAG、Skill 调用和 SubAgent 调用等场景。

### 4. Agent 产品化装配能力

开发者可以通过 AgentDefinition / AgentAssembly 装配模型、Prompt、Capability、Policy、Hook 和运行参数。业务团队不需要修改 Runtime、Session、Channel 等内核代码，就能构建面向不同网络领域的专属智能体。

### 5. Prompt / Model / Policy / Hook 分层治理

NextAgent 将模型、提示词、策略和生命周期 Hook 作为可治理资源处理。Prompt 负责生成输入，Model Profile 负责模型选择和参数，Policy / Hook 则用于上下文选择、模型路由、失败降级、审计、参数校验和结果记录。

### 6. 面向上下文分层治理

NextAgent 将用户会话、网络知识、工具结果、运行状态、长期记忆和外部系统数据纳入统一的 Context Engine 治理边界。平台可按来源可信度、Agent Scope、Owner Scope、时效性、窗口预算和安全策略分层装配上下文，并在长会话、长任务和大规模检索场景中执行上下文压缩，保留诊断结论、关键证据、约束条件和待办状态，避免把未经校验、越权或冗余的数据直接注入模型，同时支撑故障诊断、巡检分析和知识问答中的可追溯上下文供给。

### 7. 电信级工具安全体系

NextAgent 面向真实网络操作设计系统级安全闸门。危险工具不依赖 prompt 约束，而是在模型调用 Skill / Tool 时由平台执行强制检查。能力可按风险分级、网络域隔离、审批要求、执行上下文和审计粒度进行治理，降低模型幻觉导致误操作的风险。

### 8. 可观测与可审计内建

日志、Trace、Metric、Audit 和脱敏机制统一进入观测边界。平台既能支撑基础运维定位，也能记录智能体业务链路、能力调用链、用户确认和终态结果，为问题追踪、合规审计和容量治理提供依据。

### 9. Workflow 编排能力

NextAgent 支持将复杂运维任务编排为可治理的 Workflow recipe，把知识检索、模型推理、能力调用、用户交互和结果汇总组织成可追踪、可恢复的执行流程。高频、强约束或标准化运维场景可以沉淀为确定性 Workflow，降低模型自由规划带来的不确定性。

### 10. 多 Agent 协作

NextAgent 的架构支持将不同领域、不同职责的 Agent 纳入统一装配和调用边界。通过主 Agent 选择、SubAgent 调用和受控 handoff，可以让诊断、检索、分析、执行、报告等职责分工协作，同时保持 Agent Scope、能力授权和执行审计可控。

## 一句话定位

NextAgent 是一个面向电信网络运维的可治理智能体框架：用系统级安全闸门约束模型执行，用统一 Capability 体系管理领域能力，用可信 Runtime 支撑长任务运行，并通过 Workflow 与多 Agent 协作承载复杂运维流程。
