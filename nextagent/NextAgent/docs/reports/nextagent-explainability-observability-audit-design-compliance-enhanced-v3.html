可解释：说明为何这样处理、
结论依据何在

01 / 是什么

呈现模型思考过程，并说明关键结论的信息依据、选择理由、结果证据和验证程度。

02 / 为什么

帮助用户判断结论是否可信、识别尚未验证的假设，并决定是否需要补充信息或人工复核。

03 / 怎么做将模型思考、信息取舍、能力选择、执行结果和验证状态连接成可核查的结论证据链
01 / 信息依据

依据来自哪些信息

说明使用了哪些信息，哪些信息未采用或降级使用，以及相应原因。

02 / 决策理由

为何采用这项能力

说明为何采用相关查询、分析或验证能力，并区分“选择”与“执行”。

03 / 结果证据

结论依据是什么

把关键结果与最终结论建立明确对应关系，只展示必要且安全的内容。

04 / 验证程度

结论验证到什么程度

区分智能体判断、工具执行、系统验证和人工确认，明确标注未验证或降级部分。

04 / 做成什么样：结论可核查、可复核、可纠正

用户能够了解模型如何形成判断，核查依据、选择理由和未验证环节；发现偏差时，可补充信息或复核。

05 / 到什么程度：重要结论均有依据和验证状态

重要结论可追溯到对应信息和结果；未验证或降级部分明确标注；任务完成不等于结论正确。

依据：信息取舍、能力选择、执行轨迹和结果验证设计
