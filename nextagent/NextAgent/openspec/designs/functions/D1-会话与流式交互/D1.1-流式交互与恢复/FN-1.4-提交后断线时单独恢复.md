# FN-1.4 提交后断线时单独恢复

> 能力域 D1 会话与流式交互 · 子域 [D1.1 流式交互与恢复](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.2](../../../features/D1-会话与流式交互/D1.1-流式交互与恢复/F-1.2-断线重连恢复.md) |
| spec | `ts-stream-resume-replay` |
| 接口 | SSE/WS 携带新请求坐标 + `lastSeenSequence=0` |

## 描述

用户提交新请求（或重试、编辑）后，若实时通道不可用，系统立即单独恢复该请求的推送，不等待超时。

## 前置条件

- 用户已登录。
- 已提交新请求并获得请求标识与运行标识。
- 实时通道未连接、断连、重连、超时或出现间隙。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| sessionId | 是 | 会话 ID |
| requestId | 是 | 新请求的请求标识 |
| runId | 是 | 新请求的运行标识 |
| lastSeenSequence | 是 | 传 0，从该请求开头补充 |

## 输出

单独从该请求开头补充推送，补充后接续实时推送；该请求结束后回到会话级恢复规则。

## 处理过程

1. 提交返回请求标识与运行标识。
2. 若实时通道不可用，立即用游标 0 + 请求标识 + 运行标识单独恢复该请求。
3. 不等待流式活动超时。
4. 该请求终态后，回到会话级流式恢复规则。
5. 若恢复失败，明确提示用户处于断开或降级状态，不伪装成功。

## 结果

- 正常：单独恢复该请求内容，接续实时推送。
- 通道恢复后正常：回到会话级规则。
- 恢复失败：显式提示，不伪装成功。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| replay buffer 大小 | 1,000 个事件/运行 | 建议评审值 | 建议补充 |
| 兜底恢复启动时延 | <= 1,000 ms | 建议评审值 | 建议补充 |
