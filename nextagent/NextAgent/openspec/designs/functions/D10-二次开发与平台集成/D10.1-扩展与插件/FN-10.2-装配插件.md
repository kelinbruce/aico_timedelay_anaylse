# FN-10.2 装配插件

> 能力域 D10 二次开发与平台集成 · 子域 [D10.1 扩展与插件](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-10.2](../../../features/D10-二次开发与平台集成/D10.1-扩展与插件/F-10.2-装配插件.md) |
| 主规格 | `agent-scoped-plugin-composition` |
| 遗留规格 | `extension-registration` |
| 接口 | 系统内部，应用组合 |

## 描述

开发者通过配置清单启动期加载插件，插件贡献进入工具、策略和钩子治理路径。开发者可装配独立执行路由算法的官方模型驱动 plugin；plugin API `1.2` factory host 提供 closed runtime services，routing policy 保持三参数调用；backend-capable 本地 runtime 包携带可直接配置但默认未激活的官方 artifact。

## 前置条件

- 插件已在配置清单中声明。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 插件清单 | 是 | 启动期加载的插件列表；plugin API `1.2` factory 接收 closed runtime services |

## 输出

插件装配结果，贡献进入治理路径；routing policy executable 继续只接收 accepted `run`、`context` 与 cancellation signal。

## 处理过程

1. 启动期扫描配置清单加载插件。
2. 插件贡献进入工具、策略和钩子治理路径。
3. 插件不自动获得权限。
4. 插件不得替换或绕过系统的模型选择与跨模型降级规则。
5. 不支持动态热加载。
6. 系统在 startup factory materialization 时提供稳定 runtime services，插件在请求时独立执行选择；既有 policy config 继续校验并冻结；随包 artifact 仍需显式配置和 Agent policy activation。

## 结果

- 正常：插件装配完成；官方 router 通过公共 runtime ports 独立完成受治理选择。
- services 未绑定、插件无效：安全失败。
- 三参数 policy contract 保持不变；backend-capable 发行包可直接引用随包 artifact 但默认不激活。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 容量上限 | 系统最多加载 8 个插件；单插件最多贡献 4 个 Capability provider | `agent-scoped-plugin-composition`：`Plugins load only during trusted startup composition`、`Plugin providers enter the capability governance path` |
| 交付兼容性 | `plugin.json` 加目录内单文件 `.js` bundle；插件 API 版本为 `1.0`、`1.1`、`1.2` | `agent-scoped-plugin-composition`：`Plugins load only during trusted startup composition`、`插件 factory host 提供受治理 runtime services` |
| Host externals | 仅开放 `typebox` 和 `ajv` | `agent-scoped-plugin-composition`：`Plugins load only during trusted startup composition` |
| Agent 激活方式 | 插件加载与 Agent 激活分离；provider、policy、hook 必须由目标 Agent 显式绑定或激活 | `agent-scoped-plugin-composition`：`Plugin activation is explicit and Agent-scoped` |
| plugin runtime host | plugin API `1.2` factory host 提供 closed `runtime` services（`AgentAssemblyRegistry`、`CapabilityCatalog`、`CapabilityInvocationPort`、`ModelSelectionService`、`ModelInvocationService`、`PromptTemplateResolverPort` 六个 public ports）；routing policy 调用仍为 `run`、`context`、`signal` | `agent-scoped-plugin-composition`：`插件 factory host 提供受治理 runtime services` |
| 本地 runtime 包中的 router artifact | backend-only 与 with-frontend 包含 `config/plugins/agent-router-plugin/{plugin.json,index.js}`，且不自动声明或激活 router | `agent-scoped-plugin-composition`：`本地runtime包携带agent-router-plugin但不默认激活` |
| WorkflowSandboxExecutionPort 窄 port | `agent-capability` 通过 public export 暴露 `WorkflowSandboxExecutionPort`，只暴露 `runPython`；port 从同一 trusted startup `SandboxExecutionPort` 装配，经 sandbox gateway 执行、不经 capability executor 或 nl2py guardrail；app composition 只接收 port 不直接创建 `SandboxExecutionPort`/`WorkspaceFilePort` | `extension-registration`：`WorkflowSandboxExecutionPort is a capability-owned narrow sandbox port` |
