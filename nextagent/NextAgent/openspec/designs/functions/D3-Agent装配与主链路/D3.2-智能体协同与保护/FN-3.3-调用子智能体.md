# FN-3.3 调用子智能体

> 能力域 D3 Agent 装配与主链路 · 子域 [D3.2 智能体协同与保护](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-3.2](../../../features/D3-Agent装配与主链路/D3.2-智能体协同与保护/F-3.2-智能体协同处理.md) |
| spec | `agent-tool`、`invoked-agent-discovery` |
| 接口 | 子智能体工具（能力调用） |

## 描述

主智能体通过子智能体工具调用子智能体，创建独立上下文的子会话执行，调用完成后返回结果。

## 前置条件

- 主智能体已装配。
- 子智能体已注册且可用。
- 当前调用深度未超过上限。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 子智能体标识 | 是 | 要调用的子智能体 |
| 调用参数 | 是 | 传递给子智能体的输入 |

## 输出

子智能体执行结果。

## 处理过程

1. 系统校验子智能体可用性和权限。
2. 创建独立上下文的子会话和子运行。
3. 子智能体在子会话中执行，不继承父上下文。
4. 执行完成后返回结果给主智能体。
5. 子智能体调用受能力治理和风险策略约束。

## 结果

- 正常：子智能体执行完成，返回结果。
- 子智能体不可用：安全拒绝。
- 超过嵌套深度：安全拒绝。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 子智能体调用最大深度 | 1 层 | 已定义 | `agent-tool` |
| 子智能体调用超时 | 30,000 ms | 建议评审值 | 建议补充 |
| 单智能体最大子智能体数量 | 20 | 建议评审值 | 建议补充 |
