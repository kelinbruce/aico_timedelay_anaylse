## 描述

开发者通过配置清单启动期加载插件，插件贡献进入工具、策略和钩子治理路径；已激活插件可提交开发诊断记录，使用者可离线复盘插件执行轨迹。插件开发者可使用 plugin API `1.2` 的封闭 runtime service host 独立实现路由算法，运维人员可直接引用随本地 runtime 包交付且默认未激活的官方 router artifact。

## 边界

- 插件启动期加载，不支持热插拔。
- 插件不自动获得权限，需经治理路径。
- 插件不得替换或绕过系统的模型选择与失败降级规则。
- 插件开发诊断记录不得控制物理输出，原始调测内容不进入主输出面。
- plugin API `1.2` runtime host 只提供六个具名 public ports，不含 `extensions`、index signature 或动态 service lookup；随包 artifact 可用不等于启用，需显式配置与 Agent policy activation。

## 用户可依赖的质量保证

- 插件贡献只有在配置有效并通过治理后才会生效。
- 单个插件失败不会获得未声明权限或建立平行业务路径。
- LOCAL 和 REMOTE 部署提供一致的插件开发诊断产物能力，非法输入被拒绝且主输出面不接收原始调测内容；产物失败不改变受保护操作。
- 使用者无需启动 NextAgent 或上传调测内容即可离线导入诊断 NDJSON 并按会话与请求复盘每条合法执行轨迹。
