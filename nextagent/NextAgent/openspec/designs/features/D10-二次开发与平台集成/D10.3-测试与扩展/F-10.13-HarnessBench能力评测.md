## 描述

开发者与平台维护者以固定 HarnessBench 基线对当前 NextAgent 框架效果进行外部评测，覆盖基线全部 task，通过真实产品边界执行并获得逐任务终态结论、框架效果得分和可追溯的安全报告，用于横向对比框架版本效果而非阻断发布。

## 主要用例

- 以固定 HarnessBench commit 和真实模型运行条件执行全量计分评测，获得 `frameworkEffectScore` 和完整报告。
- 执行固定定向回归 profile 对 grader、terminal、sandbox 和评测基础设施进行诊断，不参与正式计分。
- 评测中断或失败后查看安全部分报告与未完成原因，定位失败阶段而不泄漏敏感内容。

## 边界

- 评测不属于发布门禁默认阻断，不定义发布阈值。
- 评测以真实 NextAgent 产品路径为准；mock 模型、固定答案、直接领域 service 调用或 NextAgent 之外的结果生成不构成评测证据。
- 评测报告不写入 credential、认证 token、完整 prompt、完整模型输出、task 文件内容或主机绝对路径。

## 用户可依赖的质量保证

- 评测清单与固定 HarnessBench commit 的完整 task catalog 恰好一致；不支持 task 排除出计分分母，全部可执行 task 无论成功失败均保留在分母，保证分母透明且结果可比较。
- 候选模型与 grader 前置条件分别校验，任一无效时 fail closed 且不发布 `frameworkEffectScore`。
- 完整计分运行即使评分覆盖退化仍发布框架效果得分，并以覆盖缺口明确标注质量；运行未完成时原子写出不含正式总分的部分报告。
- schema version 4 报告明确区分全部可执行任务与成功任务两类总体，使用互斥质量分档，避免混用不同评分字段。
- 评测失败聚合多轮安全证据并提供唯一安全失败阶段和闭集原因码；已知 stream 等待失败可区分具体边界条件，模型输出上限只作为观测事实，报告只使用 run-relative evidence ref。
