# NextAgent 特性树

> 定位：特性树以目录结构承载。能力域（D{n}）→ 子域（D{n}.{m}）→ 特性（叶子文件 F-{n}.{m}）。Feature 是用户价值聚合，主角是 actor；每个特性文件描述用户价值、主要用例、组成 Functions、适用质量属性、当前状态和权威规格导航。
>
> 与 `docs/NextAgent-feature-list.md` 的关系：扁平 list 为概览速查；本树为目录化详情版。
>
> 状态定义：稳定 / 稳定基线+在建补齐 / 在建 / 规划。事实源：`openspec/specs/` 归档=稳定；`openspec/changes/` active=在建。
>
> 特性粒度：一个 Feature = 用户/开发者能单独感知并独立评价的一个价值承诺，由一个或多个 Functions 形成。Feature 不重复定义 Requirement 或白盒实现；发生冲突时以 stable spec 为准。
