# FN-6.8 安全错误映射

> 能力域 D6 安全与治理 · 子域 [D6.3 交互与信息安全](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-6.7](../../../features/D6-安全与治理/D6.3-交互与信息安全/F-6.7-安全错误.md) |
| spec | `provider-error-safe-mapping` |
| 接口 | 系统内部，错误边界 |

## 描述

系统在错误跨越可信边界前将其标准化为安全错误，不含原始提示词、模型输出、工具结果、密钥、路径或堆栈。

## 前置条件

- 系统产生需跨边界输出的错误。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 原始错误 | 是 | 待映射的错误 |

## 输出

安全错误。

## 处理过程

1. 系统将原始错误标准化为安全错误。
2. 安全错误不含原始敏感内容。

## 结果

- 正常：安全错误输出完成。
