# FN-10.33 查看插件诊断轨迹

> 能力域 D10 二次开发与平台集成 · 子域 [D10.1 扩展与插件](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 当前状态 | 稳定 |
| 覆盖特性 | [F-10.2](../../../features/D10-二次开发与平台集成/D10.1-扩展与插件/F-10.2-装配插件.md) |
| 主规格 | `plugin-diagnostic-trace-viewer` |
| 接口 | 单个本地 HTML 文件离线打开 |

## 描述

允许开发者或运维离线导入插件开发诊断 NDJSON 文件，并按会话与请求复盘有序执行轨迹。查看器作为单个本地 HTML 文件离线运行，不依赖 NextAgent 服务、不发起网络请求、不写入持久存储，非法记录只降级自身。

## 前置条件

- 使用者能够访问查看器 HTML 文件。
- 使用者持有一份本地 UTF-8 NDJSON 文件。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 本地 NDJSON 文件 | 是 | 使用者选择的一份本地 UTF-8 NDJSON 文件 |

## 输出

- 全部不同轨迹的列表，允许选择其中任一；初始选择为文件中首次出现的合法轨迹。
- 选定轨迹的有序事件节点序列、阶段核心指标、原始记录详情和被忽略记录的问题摘要。
- 文件不含合法轨迹事件时显示无可用轨迹状态和已识别问题总数。

## 处理过程

1. 独立解析所选文件的每个非空行；空白行忽略且不计为错误。
2. 仅当顶层 `sessionId` 和顶层 `requestId` 均为非空字符串时形成轨迹事件，以精确有序组合 `(sessionId, requestId)` 作为唯一轨迹标识；不使用 `runId`、`hookInvocationId`、`payload` 内同名字段或字符串拼接后的模糊匹配替代。
3. 列出文件中全部不同轨迹；非法行按 `INVALID_JSON`、`NOT_OBJECT`、`MISSING_SESSION_ID`、`MISSING_REQUEST_ID` 检查顺序取首个匹配原因报告行号，不阻止其他合法行形成轨迹。
4. 为选定轨迹确定事件顺序：有效 `recordedAt` 时间升序，时间相同时按原始文件行号升序；缺少有效 `recordedAt` 的事件排在全部有效时间事件之后并按行号升序。
5. 按事件节点最终显示 stage 映射核心指标：`BEFORE_PLANNING` 映射 `input_question`、`AFTER_MODEL_RESULT` 按 `firstContentLatencyMs`、`modelE2ELatencyMs`、`usage`、`toolCalls` 固定顺序映射、`BEFORE_CAPABILITY_INVOKE` 映射 `capabilityId`；映射路径缺失时显示“不可用”且不隐藏同 stage 其他指标。
6. 允许展开每个节点查看该行解析所得的完整 JSON 对象；全部指标与记录内容作为文本呈现，不作为 HTML 执行。
7. 重新加载或关闭页面后先前导入内容不再可见；不发起网络请求、不写入浏览器持久存储、不修改所选文件。

## 结果

- 正常：使用者无需启动 NextAgent 或上传调测内容即可切换并复盘每条合法执行轨迹。
- 降级：单行错误只降级当前记录；文件无合法轨迹事件时显示无可用轨迹状态和已识别问题数量。

## 规格

| 规格项 | 规格值 | Requirement 来源 |
|---|---|---|
| 轨迹标识 | 顶层 `(sessionId, requestId)` 精确有序组合；不使用 `runId`、`hookInvocationId`、`payload` 同名字段或字符串拼接模糊匹配；`("ab","c")` 与 `("a","bc")` 为两条不同轨迹 | `plugin-diagnostic-trace-viewer`：`查看器按会话和请求区分执行轨迹` |
| 事件排序 | 有效 `recordedAt` 升序 → 同时间按原始行号升序 → 无效时间最后按行号升序 | `plugin-diagnostic-trace-viewer`：`查看器以确定顺序呈现轨迹事件` |
| 运行依赖 | 单个本地 HTML 文件直接打开；不依赖 NextAgent 服务、外部脚本、外部样式或外部字体，不发起网络请求，不写入浏览器持久存储，不修改所选文件 | `plugin-diagnostic-trace-viewer`：`查看过程保持本地只读边界` |
| 伴随交付 | 本地运行包含官方 `developer-hook-trace` 插件时，其插件目录同级包含 `trace-viewer.html`；插件 loader 不读取或执行该文件 | `plugin-diagnostic-trace-viewer`：`查看器作为本地运行包的插件伴随文件交付` |
