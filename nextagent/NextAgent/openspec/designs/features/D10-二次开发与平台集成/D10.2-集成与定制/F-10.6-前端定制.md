## 描述

系统提供外部 UI 定制契约、多宿主模式、结构化消息渲染和组件注入，支撑前端与后端协同。Process Detail 中已挂载的 PIU 定制视图在视觉折叠间保留同一交互实例，只在 owner 移除时结束前端容器生命周期。平台集成方可以在 AICOConfig 中按 Capability kind、技术标识和语言为扩展 Tool、Agent、Skill、Workflow 配置纯文本业务名称，无需修改或重新构建前端产物。

## 边界

- 配置不热加载，经手写校验。
- 定制不影响后端边界。
- 支持配置契约、组件注入、布局模式、展示控制和多宿主模式。
- 视觉折叠不等于 PIU owner 销毁：已挂载 PIU 只隐藏并禁止交互，未查看 PIU 不预挂载，非 PIU Detail 保持折叠卸载。
- 过程条目或 run scope 移除时卸载 PIU Detail、阻止迟到 emit 并清空容器；不定义 host 未提供的外部资源销毁协议。
- AICOConfig 名称只覆盖平台内置 Capability 之外的扩展身份；平台固定名称、固定标题模板、执行状态和结果披露策略不受 AICOConfig 覆盖。
- 配置名称只作为纯文本渲染，缺失、部分非法或未知时安全降级，不阻塞对话、过程历史或最终答案。
