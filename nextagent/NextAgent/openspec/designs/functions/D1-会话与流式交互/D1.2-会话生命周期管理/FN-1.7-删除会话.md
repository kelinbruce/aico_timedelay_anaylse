# FN-1.7 删除会话

> 能力域 D1 会话与流式交互 · 子域 [D1.2 会话生命周期管理](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.3](../../../features/D1-会话与流式交互/D1.2-会话生命周期管理/F-1.3-管理会话.md) |
| spec | `session-delete` |
| 接口 | `DELETE /api/v1/sessions/:sessionId` |

## 描述

删除当前归属下的会话及其从属事实。

## 前置条件

- 用户已登录。
- 目标会话属于当前用户和智能体。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| sessionId | 是 | 会话 ID |

## 输出

成功返回 204 No Content，无响应体。

## 处理过程

1. 系统校验目标会话属于当前用户归属和智能体归属。
2. 在单一事务中物理删除会话及标注、分享等从属事实。
3. 不隐式取消未结束的请求。

## 结果

- 正常：删除成功，返回 204。
- 会话不存在或不属于当前用户：安全拒绝，不暴露会话是否存在。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 删除事务超时 | 5,000 ms | 建议评审值 | 建议补充 |
