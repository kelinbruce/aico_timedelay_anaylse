# FN-4.4 摘要压缩历史对话

> 能力域 D4 模型与上下文 · 子域 [D4.2 上下文管理与压缩](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-4.4](../../../features/D4-模型与上下文/D4.2-上下文管理与压缩/F-4.4-压缩长对话.md) |
| spec | `context-engine` |
| 接口 | 系统内部，摘要压缩服务 |

## 描述

系统通过模型生成摘要压缩较早的历史对话，保留可追溯引用。

## 前置条件

- 上下文使用达到压缩阈值。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 较早的历史对话 | 是 | 需压缩的历史内容 |

## 输出

摘要和可追溯引用。

## 处理过程

1. 系统识别需要压缩的较早历史对话。
2. 通过模型生成摘要。
3. 用摘要替换原历史，保留可追溯引用。
4. 摘要压缩可取消。

## 结果

- 正常：压缩成功，生成摘要和引用。
- 压缩失败：安全处理，不影响请求。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 摘要最大长度 | 8 KiB | 建议评审值 | 建议补充 |
| 压缩触发阈值 | >= 80% 上下文窗口 | 建议评审值 | 建议补充 |
| 摘要生成超时 | 30,000 ms | 当前实现值 | `default-system.yaml` |
