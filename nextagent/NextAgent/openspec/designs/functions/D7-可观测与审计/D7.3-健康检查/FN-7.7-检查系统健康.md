# FN-7.7 检查系统健康

| spec | `system-health-check` |
| 接口 | `GET /api/v1/health` 等 |

## 描述

检查系统健康、就绪和存活状态，返回核心指标，诊断输出使用安全事实。

## 前置条件

- 系统运行。

## 输入

无。

## 输出

健康状态和核心指标。

## 处理过程

1. 系统检查健康、就绪和存活状态。
2. 返回核心指标。
3. 诊断输出使用安全事实，不含敏感信息。

## 结果

- 健康：系统正常运行。
- 不健康：系统异常，返回安全诊断。
