## 描述

用户可以从已完成的助手回复新建子会话，复制到该回复为止的对话内容和可用的只读过程快照；快照引用子会话自己的消息，因此源会话删除后仍可独立恢复。

## 边界

- 只复制从开头到锚点消息的对话前缀和子会话拥有的只读过程快照；不复制可操作运行状态、检查点、待确认输入或工具状态。
- 源消息必须是已持久化、可见、可渲染的助手消息。
- 子会话上下文初始化为空，并记录派生来源元数据。
- 过程 `messageId` 必须映射到复制前缀内的 child message；无法安全映射时整个派生事务失败，不能删除引用后继续。
- 刚派生且尚无新提问的子会话，其最新继承轮次满足既有界面条件时可直接发起 retry 或 edit；`forkInherited` provenance 标记只标识消息来自 copied prefix，不决定操作可用性，最终资格由后端权威校验决定。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 最新继承轮次操作可用性 | 满足既有 latest、transition、permission 和 retry 上限条件时，最新继承轮次可发起 retry/edit；`forkInherited` 不单独禁用入口 | `session-fork-from-message`：`Copied message 携带继承 provenance 标记`、`request-retry`：`Agent Web 对可操作的最新轮次暴露 retry 入口`、`request-edit-resubmit`：`Agent Web SHALL expose edit only for the current latest turn` |
