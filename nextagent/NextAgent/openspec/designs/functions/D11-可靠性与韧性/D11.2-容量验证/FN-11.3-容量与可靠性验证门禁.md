# FN-11.3 容量与可靠性验证门禁

> 能力域 D11 可靠性与韧性 · 子域 [D11.2 容量验证](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-11.3](../../../features/D11-可靠性与韧性/D11.2-容量验证/F-11.3-容量与可靠性验证.md) |
| spec | 在建 `add-ts-performance-test-gate`、`add-ts-reliability-test-gate` |
| 接口 | 验证门禁命令 |

## 描述

系统按测试类别运行验证门禁：性能门禁验证吞吐与时延，可靠性门禁验证故障与边界恢复。两类门禁共享同一执行入口，仅测试场景类别不同。

## 前置条件

- 验证环境已就绪。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 测试类别 | 是 | 性能或可靠性 |
| 测试场景 | 是 | 对应类别的压测或边界场景 |

## 输出

验证结果（通过/失败及指标）。

## 处理过程

1. 系统按测试类别选择门禁。
2. 运行对应测试场景。
3. 校验指标是否达标。

## 结果

- 通过：指标达标。
- 失败：指标未达标。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 门禁阈值 | 待 active change 归档后固化 | 在建 | `add-ts-performance-test-gate`、`add-ts-reliability-test-gate` |
