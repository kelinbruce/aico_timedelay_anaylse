## 用户价值

系统提供跨会话的长期记忆，模型通过记忆工具显式调用，记忆有提取和老化生命周期（默认关闭），并支持用户通过管理界面批量迁移和备份个人记忆；管理批量新增支持一次提交 1 至 100 条个人记忆并返回可核对的部分成功结果，使导入场景在服务端形成统一的有界写入契约。共享知识管理在保留发布者稳定标识的同时展示可读用户名，查询失败或缺失时回退稳定标识，保持列表可用。已提供记忆管理入口的 Agent Web 宿主以统一的本地化名称、无障碍名称、记忆图形语义和页面标题呈现该管理能力，同时保留各宿主原有菜单范围。这些能力不阻塞请求终态。

## 主要用例

- 用户通过固定 JSON 模板批量准备长期记忆，在写入前检查、删除并确认。
- 用户按当前个人记忆 Tab 和筛选条件导出完整、本地化且公式安全的 CSV 备份。
- 显式检索与当前问题相关的记忆，再按 id 查看必要详情。
- 写入结构化记忆，并在重复或版本冲突时先查询现状。
- 在启用时异步提取、老化或恢复记忆，而不阻塞用户请求终态。

## 黑盒边界

- 上下文装配不自动注入记忆，模型需要时显式调用。
- 记忆不阻塞请求终态提交。
- 记忆提取和老化默认关闭。
- 后台记忆提取遵守统一的模型选择和提示词治理，并且不会伪造请求运行状态。
- 只读记忆 Tool 可在统一幂等瞬态门禁内重试；`add_memory` 保持非幂等且不自动重放，全部 Tool 复用统一 outer safe error 和大结果边界。
- 批量导入不接受共享记忆或服务端权威字段；筛选导出不包含共享记忆。
- 管理批量新增每批 1 至 100 条，逐项独立校验、内容安全准入和幂等写入，返回成功数、失败数和成功记忆标识；单项失败不阻止后续条目，请求级 scope/取消/存储不可用使整批安全失败。

## 适用质量属性

- 记忆始终按 Owner Scope 与 Agent Scope 隔离，并在明确调用时使用。
- 后台提取或老化失败不阻塞请求终态，也不会向主路径注入伪造事实。
- 导入继续由服务端执行最终容量、安全和幂等裁决；导出把用户可控单元格作为文本处理，避免表格公式注入。
