# 评估
## 功能特性数据查询
- 业务价值区域评估任务-价值区域查询：指定区域/评估模板下的价值区域、GIS、导出列表。
- 网络隐患评估指标查询：查询区域、网格、站点隐患打分、风险等级、隐患明细，支持按时间维度导出评估报表。
- 业务感知质量评估结果查询：指定片区查询用户感知KPI、质差小区清单、评估样本数据、GIS可视化展示。
- 资源负荷评估数据分析：查询全网/区域小区负载、资源利用率评估结果，输出负荷分布清单与统计报告。
- 评估任务执行日志查询：检索历史评估任务运行状态、任务参数、执行耗时、异常失败明细、原始评估数据源。

## 策略意图
- 1min监控任务启停与参数调整：启停1min监控，调整监控时间和区域。
- 批量评估任务创建与调度：新建、暂停、终止周期性网络评估任务，修改评估范围、执行周期、输出模板。
- 评估阈值模板生效切换：启用/停用自定义风险评估阈值模板，批量下发区域评估判定规则。
- 评估报告定时推送启停：开启或关闭评估日报、周报自动生成、邮件/平台消息推送策略。

# 韧性
## 功能特性数据查询
- 智网光伏协同续航运行优化分析：光伏协同续航运行状态、优化效果、收益、宕站、节能编排、优化报告。
- 区域停电风险仿真结果查询：查询预设停电场景下站点备电时长、断网风险区域、储能可用容量、仿真明细。
- 储能备电资源台账查询：按区域/站点查询储能电池SOC、健康状态、历史充放电记录、最大备电时长。
- 韧性演练执行记录查询：检索历史大停电演练任务、站点切换记录、业务中断时长、演练效果汇总数据。
- 链路容灾能力分析查询：查询骨干链路故障后的业务迁移路径、覆盖保留范围、容灾切换时延统计。

## 策略意图
- 区域大停电备电任务启停：打开/关闭区域大停电备电任务。
- 储能充放电自动策略启停：开启/关闭光伏+储能协同自动充放电调度，调整峰值放电触发条件。
- 故障容灾自动切换策略管控：启用/停用站点链路故障自动倒换、小区业务迁移容灾策略。
- 韧性仿真任务调度控制：启动、中止、删除停电风险仿真任务，修改仿真场景与覆盖范围。

# 优化
## 功能特性数据查询
- 查询全网区域网格的打分情况：查询全网、区域或网格的优化与维护打分情况。支持查看各网格的打分总览列表，以及按小区、时间等条件查询指定网格的打分详情。
- 小区射频优化方案查询：查询候选小区功率、信道调整方案、预估KPI变化、优化前后对比数据。
- VIP用户体验监测数据查询：查询VIP小区话务指标、时延、切换成功率、质差时段明细。
- 优化策略执行效果回溯查询：检索历史优化指令下发记录、小区生效状态、优化收益指标统计。
- 覆盖干扰分析结果查询：查询小区重叠覆盖、干扰源清单、优化候选小区列表，支持GIS导出。

## 策略意图
- 体验优化开通和关闭：启动/停止体验优化、动态话务、VIP组、叠加包体验优化。
- 小区射频参数自动优化启停：开启/关闭功率、信道、偏置参数自动调优任务，限定优化区域范围。
- 负荷均衡优化策略管控：启用/停用小区间动态负载均衡、邻区切换参数自适应优化策略。
- 优化方案定时批量下发控制：开启/关闭周期性优化策略自动下发，设置下发执行时间窗口。

# 维护
## 功能特性数据查询
- 单站智能备电方案及结果查询：少量站点停电、备电方案、收益效果。
- 站点故障智能诊断结果查询：查询故障站点根因分析、推荐处置方案、故障影响小区清单、恢复预估时长。
- 工单闭环维护记录查询：按区域/站点查询运维工单、处置进度、历史故障重复发生统计。
- 基站设备运行状态查询：站点电源、传输、射频模块实时状态、历史告警序列、隐患预警信息。
- 站点改造方案效果预评估查询：查询站点搬迁、新增邻区等改造方案覆盖、干扰预估结果。

## 策略意图
- 单站智能备电管理启停：开启/关闭区域或站点单站备电管理。
- 站点故障自动派单策略启停：启用/关闭故障智能识别后自动生成运维工单策略。
- 站点告警降噪策略管控：打开/关闭重复告警合并、低等级告警抑制过滤规则。
- 站点周期性巡检任务调度：启动、暂停全域/指定网格自动化站点巡检任务。

# 节能
## 功能特性数据查询
- 导出基于工参的节能小区共覆盖结果：节能小区与基础覆盖小区共覆盖关系。
- 小区节能收益统计查询：按区域、时段查询小区通道休眠、载波关断产生的节电数据、KPI波动情况。
- 节能策略候选小区清单查询：筛选满足休眠、通道关断条件小区，查询邻区覆盖保障能力。
- 节能任务执行明细查询：查询每日节能指令下发清单、小区执行成功/失败记录、策略生效时长。
- 电价联动节能仿真分析：查询峰谷电价下不同节能策略的节电成本、业务风险预估数据。

## 策略意图
- 取消节能优化建议下发：取消小区未来1天节能优化建议下发。
- 小区载波/通道休眠策略启停：开启或关闭指定区域小区闲时载波、射频通道自动休眠策略。
- 分时节能规则启用管控：生效/失效基于时段、话务门限的动态节能调度规则。
- 节能策略灰度下发开关控制：开启/关闭节能方案分批次灰度下发，控制试点区域范围。
