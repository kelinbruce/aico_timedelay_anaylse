## 用户价值

系统支持 Skill 的发现、调用、资源访问和远端获取；Skill 可用 canonical model options（包括 `toolChoice`）受治理地影响当前 request/run，且始终按归属治理。

## 主要用例

- 发现当前 Agent 可用的系统级或 Agent-owned Skill。
- 由普通 Agent 通过 Skill Tool 内联/分叉执行，或由可信请求定向执行。
- 访问 Skill 声明资源或获取远端候选，并保持 source identity 与 scope 校验。
- 通过受治理 metadata 为当前 request/run 提供 Prompt 与 model options。

## 黑盒边界

- 技能分内置、系统和智能体三级，智能体自有技能优先于系统级。
- 技能执行支持内联和分叉。
- 技能需经治理路径才可用。
- Skill 可使用稳定模型标识和受治理的模型选项，但不能通过执行输入任意扩大模型接入权限。
- `SkillMetadata.modelOptions.toolChoice` 只接受 `AUTO | NONE | REQUIRED`；省略时不覆盖，不接受 named-tool object 或 provider-native alias。

## 适用质量属性

- Skill 的发现、调用和资源访问始终受 Agent Scope 与能力治理约束。
- Skill 配置无效、不可用或越权时安全失败，不影响其他有效 Skill。
