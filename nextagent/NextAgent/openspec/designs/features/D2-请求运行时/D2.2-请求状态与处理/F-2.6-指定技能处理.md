## 用户价值

用户或受信入口可以明确指定某个 Skill 处理请求，避免普通 Agent 自由选路带来的不确定性。系统在执行前确认该 Skill 对当前 Agent 可见且获准，并用统一结果清楚表达成功、失败或取消。

## 主要用例

- 通过可信 `routingConstraints.targetSkill` 指定已披露 Skill。
- 通过有效 `$skill:` directive 定向执行，并把剩余文本作为实际问题。
- Skill 不可用、隐藏、越权或执行失败时获得防枚举的安全结果。

## 黑盒边界

- 指定技能经可用性、权限和智能体归属校验。
- 校验失败安全拒绝。
- 定向 Skill 的最终失败不会回退到普通模型选路，也不会在调用边界外再次自动重试。
- 同一请求只形成一个明确路由目标；冲突 directive 或不可信客户端字段不能扩大权限。

## 适用质量属性

- 确定性：定向请求不回退为普通 Agent 自由选路。
- 安全性：隐藏与不存在目标使用防枚举语义，scope 只来自可信边界。
- 一致性：定向执行复用统一 Capability 最终结果和取消语义。
- 可维护性：directive parsing、routing 和 Skill execution 各由单一 owner 承载。
