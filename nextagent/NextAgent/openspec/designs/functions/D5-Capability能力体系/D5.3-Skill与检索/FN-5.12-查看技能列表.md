# FN-5.12 查看技能列表

> 能力域 D5 Capability 能力体系 · 子域 [D5.3 Skill 与检索](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-5.6](../../../features/D5-Capability能力体系/D5.3-Skill与检索/F-5.6-Skill系统.md) |
| spec | `web-skill-catalog` |
| 接口 | `GET /api/v1/skills` |

## 描述

查看当前可用的技能列表，供前端展示和选择。

## 前置条件

- 用户已登录。

## 输入

无。

## 输出

技能列表（含标识、名称、描述）。

## 处理过程

1. 系统按当前用户和智能体归属过滤。
2. 返回可用技能列表。

## 结果

- 正常：返回技能列表。
- 无技能：返回空列表。
