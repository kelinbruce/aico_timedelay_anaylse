## 描述

用户可以创建、查询和删除会话，系统按用户归属和智能体归属双重隔离，支撑运维人员多会话工作流。

## 边界

- 会话按用户归属和智能体归属双重隔离，用户只能看到和操作属于自己的会话。
- 删除会话时物理删除会话及其从属事实（标注、分享等），不引入回收站或软删除。
- 删除不会隐式取消未结束的请求。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 会话列表默认分页 | 50 | 已定义 | `session-history-search` |
| 搜索分页默认/上限 | 20 / 50 | 已定义 | `session-history-search` |
| 搜索词长度限制 | ASCII 至少 3 字符，非 ASCII 至少 2 字符，最大 50 字符 | 已定义 | `session-history-search` |
| 搜索时间范围上限 | 90 天 | 已定义 | `session-history-search` |
| 删除方式 | 物理删除，无回收站/软删除 | 已定义 | `session-delete` |
| 删除范围 | 会话及标注、分享等从属事实 | 已定义 | `session-delete` |
