# FN-10.5 集成外部系统

> 能力域 D10 二次开发与平台集成 · 子域 [D10.2 集成与定制](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-10.5](../../../features/D10-二次开发与平台集成/D10.2-集成与定制/F-10.5-集成外部系统.md) |
| 主规格 | `gateway-configuration`、`watermark-gateway` |
| 遗留规格 | `fullstack-packaging-boundary` |
| 接口 | 网关边界 + 全栈托管 |

## 描述

开发者通过网关边界集成外部存储、远端服务和业务 API，前端经构建后 npm 包托管。集成方可通过外部 URL 提供水印服务，NextAgent 经 `WatermarkGatewayPort` 受治理出口在 channel 层对返回文本做透明替换，水印默认关闭。集成方还可以为 LOCAL 或 REMOTE 部署注册用户查询 Gateway，为共享知识等消费场景提供可读用户名展示。

## 前置条件

- 网关或接入扩展已配置。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 集成配置 | 是 | 网关、远端服务或前端托管配置 |
| 用户查询请求 | 用户查询时 | 可信 `tenantId`、当前调用者 `subjectId` 和 1..10000 个互不重复的 `targetSubjectIds` |

## 输出

集成结果。用户查询返回 `UserQueryResult`，只包含请求目标集合中已解析用户的 `subjectId` 和 `userName`（1..256 个 Unicode code point）；LOCAL 默认部署为每个目标标识返回 `${subjectId}-name`。

## 处理过程

1. 外部存储、远端服务、业务 API 经网关边界接入；环境相关 HTTP transport 可通过可选通用 `FetchGateway` 装配。
2. 本地原子事务以一致性为先。
3. 模型信息只在实际查询时访问远端服务，应用启动和 Agent 配置发布不会触发远程查询。
4. Web API 只暴露公共数据对象。
5. 前端经构建后 npm 包托管，不直接依赖源码。
6. 水印服务经 `WatermarkGatewayPort`（REMOTE-only）接入，在 composition 边界适配为 `WebWatermarkPort` 注入 channel 层；channel 层对 ASSISTANT 正文（`LLM_CONTENT_DELTA`、`REQUEST_COMPLETED`、workflow `TOOL_STRUCTURED_DELTA`、历史回显 ASSISTANT 消息）在 content > 500 时调用水印服务替换文本，fail-open 原文返回，不修改持久化数据。
7. 用户查询 Gateway 经正式 `user-query` adapter 注册：启动期选择并校验 provider 和 binding，LOCAL 默认部署提供 `local-user-query` 确定性实现，REMOTE 部署由受信集成方提供同一契约的实现。运行期只调用冻结的有效 binding，取消、非法输入或未授权目标出现时产生确定且不泄漏的可观察结果。

## 结果

- 正常：外部系统集成成功。
- 网关不可用：安全失败。
- 用户查询成功：返回有序用户结果，省略不存在或无权查看的目标用户。
- 用户查询取消：返回 category 为 `CANCELED` 的 `SafeError`，不返回部分结果。
- REMOTE `user-query` 缺少 provider：启动在 ready 前失败，不回退 LOCAL。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 网关选择时点 | 启动期完成选择、校验和冻结；运行期不切换或回退到另一 adapter | `gateway-configuration`：`Gateway configuration is loaded and stabilized during startup`、`Adapter selection is a static per-port deployment decision` |
| 通用 HTTP transport | `FetchGateway` 为可选能力；LOCAL 可不装配，多个来源同时提供时启动失败 | `gateway-configuration`：`Gateway configuration is loaded and stabilized during startup` |
| REMOTE 入口失败 | 缺少或不可用时启动失败，不回退到 LOCAL | `gateway-configuration`：`Package launcher selects deployment entrypoint from frozen deployment mode` |
| 用户查询公共契约 | `UserQueryGateway.queryUsers` 接收可信 `tenantId`、`subjectId` 和 1..10000 个互不重复 `targetSubjectIds`；返回 `UserProfileRecord` 数组，每项只含 `subjectId` 和 `userName`（1..256 Unicode code point）；结果按请求顺序、不重复、只含请求目标；省略用户不泄漏存在性；取消返回 `CANCELED` SafeError | `gateway-configuration`：`用户查询 Gateway 提供稳定公共契约` |
| 用户查询 adapter 注册 | `user-query` 属于稳定 `GatewayAdapterKind`；`GatewayBindings.userQuery?` 为唯一 binding 位置；LOCAL 默认包含 `local-user-query` 并返回 `${subjectId}-name`；REMOTE 缺 provider 启动失败不回退 LOCAL；provider 返回未选择或冲突 binding 启动失败 | `gateway-configuration`：`用户查询 Gateway 通过正式 adapter 注册` |
| 水印受治理出口 | `WatermarkGatewayPort` 为水印服务唯一出口，channel 层经 `WebWatermarkPort` 消费，MUST NOT 绕过 gateway 直连；REMOTE-only，LOCAL entry 被过滤 | `watermark-gateway`：`WatermarkGatewayPort is the sole governed egress to the watermark service`、`Watermark requires a REMOTE gateway entry and provider` |
| 水印默认关闭 | `config/config.json` 的 `watermarkEnabled` 默认 `false`；文件/字段缺失返回 `false` 不抛异常 | `watermark-gateway`：`Watermark is disabled by default and controlled by config` |
| 水印作用对象 | 仅 ASSISTANT 正文（`LLM_CONTENT_DELTA`、`REQUEST_COMPLETED`、workflow `TOOL_STRUCTURED_DELTA`、历史回显 ASSISTANT）且 content > 500；USER/CAPABILITY_RESULT/SUMMARY/thinking/CLIP-Bash 不加水印 | `watermark-gateway`：`Watermark transform targets ASSISTANT content above 500 characters` |
| 水印 fail-open | 调用失败原文返回，不阻断 stream/API，日志记录不暴露错误；不修改持久化数据 | `watermark-gateway`：`Watermark service failure degrades to original content`、`Watermark does not modify persisted data` |
