## 描述

模型通过该工具向用户提问，创建待确认输入，等待用户回答后继续处理。

## 前置条件

- 请求正在执行。
- 未超过待确认输入数量上限。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 问题内容 | 是 | 向用户提出的问题 |
| 选项 | 否 | 可选的回答选项 |

## 输出

创建待确认输入，暂停请求等待用户回答。

## 处理过程

1. 模型调用该工具提出问题；系统在创建 pending input 前一次返回当前阶段全部可独立判断的安全参数违规。
2. 合法调用创建 runtime-owned pending input 并暂停请求；非法调用产生与原 tool call 配对的 canonical 安全结果。
3. 所有非取消失败反馈模型，由模型修正、再次调用或选择替代；不建立独立纠错次数或相同失败阈值。
4. 用户回答后，请求恢复，答案重新进入校验和上下文预算。
5. 该工具不创建第二套交互状态；取消保持取消，达到 `maxTurns` 时复用统一单次模型收尾。

## 结果

- 正常：创建待确认输入，等待用户回答。
- 超过数量上限：安全拒绝。

## 规格

| 规格项 | 规格值 | 权威来源 |
|---|---|---|
| 单个问题的预定义选项数量 | 每个问题二至十五个预定义选项 | `ask-user-question-tool`：`单个问题支持至多十五个预定义选项` |
| 失败反馈边界 | 无独立纠错次数或相同失败阈值；全部非取消失败反馈模型，普通轮次耗尽后进入且仅进入一次无 Tool 执行权的模型收尾 | `ask-user-question-tool`：`AskUserQuestion 可纠正输入错误进入安全模型纠错` |
