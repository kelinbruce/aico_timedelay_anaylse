# FN-8.7 保存产物引用

> 能力域 D8 数据与记忆 · 子域 [D8.3 附件与产物](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-8.5](../../../features/D8-数据与记忆/D8.3-附件与产物/F-8.5-产物引用.md) |
| spec | `large-content-references` |
| 接口 | 系统内部，产物引用 |

## 描述

系统保存产物元数据和引用，受归属隔离，首版不提供下载入口。

## 前置条件

- 产物产生。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 产物元数据 | 是 | 产物的元信息 |

## 输出

产物引用。

## 处理过程

1. 系统保存产物元数据和引用。
2. 产物引用受归属隔离。

## 结果

- 正常：产物引用保存成功。
