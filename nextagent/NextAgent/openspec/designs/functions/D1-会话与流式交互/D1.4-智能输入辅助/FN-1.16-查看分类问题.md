# FN-1.16 查看分类问题

> 能力域 D1 会话与流式交互 · 子域 [D1.4 智能输入辅助](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.9](../../../features/D1-会话与流式交互/D1.4-智能输入辅助/F-1.9-智能问题推荐.md) |
| spec | `category-question-api`、`category-question-source` |
| 接口 | `GET /api/v1/category-questions` |

## 描述

查看按分类组织的预设问题，用户可点击分类后选择具体问题。

## 前置条件

- 用户已登录。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| locale | 否 | 语言偏好 |

## 输出

```json
{
  "categories": [
    {
      "category": "故障诊断",
      "questions": [
        { "text": "分析小区掉话率升高原因", "fixed": true, "hash": "..." }
      ]
    }
  ]
}
```

## 处理过程

1. 系统从智能体资源目录加载分类问题数据。
2. 按当前语言返回分类和问题。

## 结果

- 正常：返回分类问题列表。
- 无预设数据：返回空列表。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 分类问题数据大小 | 5 MiB/智能体 | 建议评审值 | 建议补充 |
