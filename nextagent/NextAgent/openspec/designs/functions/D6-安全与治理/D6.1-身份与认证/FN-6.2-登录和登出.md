# FN-6.2 登录和登出

> 能力域 D6 安全与治理 · 子域 [D6.1 身份与认证](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-6.2](../../../features/D6-安全与治理/D6.1-身份与认证/F-6.2-本地认证.md) |
| spec | `ts-local-configured-auth` |
| 接口 | `POST /api/v1/auth/local/login`、`POST /api/v1/auth/local/logout` |

## 描述

用户通过本地认证登录，获得签名 Cookie；登出后 Cookie 失效。

## 前置条件

- 用户有凭证（来自环境变量或文件引用）。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 用户名 | 是 | 登录用户名 |
| 密码 | 是 | 登录密码 |

## 输出

登录成功设置签名 Cookie，返回安全身份摘要；登出清除 Cookie。

## 处理过程

1. 登录：校验凭证，成功后设置签名 HttpOnly Cookie。
2. 登出：清除本地认证 Cookie，不删除用户数据。
3. 登录失败有限速。

## 结果

- 登录成功：设置 Cookie，返回身份摘要。
- 登录失败：安全拒绝，限速。
- 登出成功：清除 Cookie。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| Cookie 过期时长 | 8 小时 | 建议评审值 | 建议补充 |
| 登录失败限速 | 3 次失败后阻断 500 ms | 当前实现值 | `ts-local-configured-auth` |
| 单用户活动登录票据数 | 5 | 建议评审值 | 建议补充 |
