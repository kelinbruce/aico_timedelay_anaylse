- [x] 2.1 在 `agent-context-engine` 中新增/演进 prompt template registry：registry 初始化时必须从 `packages/agent-context-engine/prompt-templates/builtin/` 编译 process-scoped builtin bucket，builtin facts 不绑定 `agentId/agentVersion`，builtin `templateRef` 不包含 `agentId/agentVersion`；同时对 `agent-app` 暴露唯一 Agent prompt 装配期写入口 `register({ agentId, agentVersion, path })`，其中 `path` 是 agent-app/package assembly 完成 package-root containment 后组装出的受信绝对 Agent prompt root 路径；该入口拥有 Agent prompt root 扫描、manifest parser、schema/semantic validation、`PromptTemplate` materialization、包含 `agentId/agentVersion` 的 Agent-scoped `templateRef` derivation 和 registry publication；registry 承载 builtin bucket 与 Agent-scoped bucket，不把 builtin facts 复制到每个 Agent。

- [x] 2.4 在 `agent-app` / `agent-package-assembly` 中只解析受信 prompt root：定位 Agent package `prompts` 根目录，做 package-root containment，并形成绝对 `path`；不得在 app/package assembly 中扫描 manifest、解析 prompt manifest 语义、派生 `templateRef`、构造 `PromptTemplate` 或单独 publish registry facts。

- [x] 3.4 修正同层冲突判断：冲突 key 为同一 source layer 内同 purpose 的最高 specificity 匹配集合，不得把同 layer 中不同 purpose 或不同 match 条件且非最高 specificity 的候选简单判为冲突；最高 specificity 并列时必须 fail safely。

- [x] 3.6 补充 selector/compatibility tests：只从 process-scoped builtin bucket 与当前 Agent bucket 的逻辑并集选择、不会选择其它 Agent-scoped template 或未注册 template、compatible model ids 只能由 `resolveModelSelection(...)` 内部 helper 从 `agent` source 且显式 `match.model` 的 matched templates 和 safe model candidates 推导、builtin/generic/fallback template 不贡献 compatible ids、empty compatible ids 不约束模型、helper 不返回 template identity、不渲染 prompt、`match.model` 只作为兼容条件和 selected model specificity、final model selection 使用 patch/default/order tie-break、assembler 用必填 selected model 按 model specificity 选最终 template、agent default 覆盖 builtin matched、同层最高 specificity 规则稳定、同层等价冲突 fail closed、无 Agent 匹配时使用 builtin fallback、consumer 不能传 template id 越权选择、safe error/observation 只含 safe ids/reason。
