## 能力追踪规则

- 所有 122 个用例都引用 `F-10.8`、`FN-10.31` 和本 change 的对应 Requirement。
- `TC-SI-001..111`、`TC-SI-120..122` 还必须引用来源场景覆盖的稳定 Feature、Function 和 Requirement；不能只引用门禁 Function。
- `TC-SI-112..119` 必须引用其验证的 gateway、SkillHub、remote deployment、runtime、channel 或 agent-web 稳定 Function；其中 `113/114/117/118/119` 分别以 `workflow-remote-execution-mode`、`skillhub-source`、`skill-catalog-query`、`skill-resource-access`、`ts-web-sse-ws-transports`、`ts-stream-history-consistency` 和 `ts-stream-resume-replay` 的适用 Requirements 为产品行为依据。
- 机器 manifest 是精确追踪源；本文是评审用可读投影，二者漂移时 source-sync 必须失败。
