# FN-5.11 获取远端技能

> 能力域 D5 Capability 能力体系 · 子域 [D5.3 Skill 与检索](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-5.6](../../../features/D5-Capability能力体系/D5.3-Skill与检索/F-5.6-Skill系统.md) |
| spec | `skillhub-source` |
| 接口 | 远端网关（技能中心） |

## 描述

通过技能中心获取远端技能，安装并校验后进入能力目录。

## 前置条件

- 技能中心可用。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 技能标识 | 是 | 要获取的远端技能 |

## 输出

安装结果。

## 处理过程

1. 通过远端网关刷新、搜索、下载技能。
2. 安装技能包。
3. 校验清单和治理通过后才进入目录。
4. 嵌套资源被拒绝。

## 结果

- 正常：安装成功，技能进入目录。
- 校验失败：安全拒绝。
- 技能中心不可用：安全失败。
