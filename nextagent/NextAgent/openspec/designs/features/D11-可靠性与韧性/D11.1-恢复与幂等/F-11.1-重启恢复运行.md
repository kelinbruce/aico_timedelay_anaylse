## 用户价值

服务进程重启或实例接管后，用户已提交的任务不会静默丢失、重复产生副作用或重新开始已消耗的 Agent 轮次。系统依据持久化事实恢复同一运行；无法证明安全继续时，会给出明确失败而不是猜测执行。

## 主要用例

- 恢复已排队或执行中的请求，并继续向原会话交付可观察状态。
- 接管终态尚未完整提交的运行，幂等地收敛为唯一终态。
- 恢复含 Tool calls、pending input 或 finalizing turn 的运行，不重复执行不安全动作。

## 黑盒边界

- 恢复按可信事实分类（排队、执行中、终态待定、终态）。
- 非幂等能力调用前检查幂等声明，默认非幂等。
- 复合操作在单一事务内完成。
- checkpoint 与 `RequestContext` 保存同一个 `agentTurnIndex`；pause、resume 和 crash recovery 不重置 `maxTurns`，已进入 finalizing 的 run 不返回 normal turn。
- 已有 terminal fact 不会再次 terminal commit；不能安全重放的 pending Capability 不会重复执行。

## 适用质量属性

- 可靠性：恢复后继续同一 logical turn，finalizing 最多一次。
- 一致性：同一运行只有一个权威终态，复合持久化保持原子性。
- 安全性：默认禁止非幂等重复副作用，恢复失败使用安全错误。
- 可诊断性：恢复分类和失败阶段可通过低基数诊断定位，不泄漏请求内容。
