## 描述

用户提交问题后，系统将处理过程实时推送至前端。已持久化的执行说明、Tool 调用和 Tool 结果只由消息拥有正文，事件提供顺序、状态和强引用；SSE 与 WebSocket 使用同一服务端安全投影。用户已经看到的执行说明和 Tool 结果在完成边界保持连续：同一订阅已交付的非空安全累计正文原地收敛为完成态，不因消息短暂不可读而清空；缓存未命中、刷新和恢复场景仍以持久化会话消息为唯一正文来源。Tool 前说明在无独立步骤语义的桥接位置连续连接 thinking 与 Tool；最终答案只随 Web stream 的逐帧投影推进，并在接管待定正文时直接稳定显示在既有答案位置。

## 边界

- 前端只负责展示后台处理过程，不自行创造处理状态或最终结果。
- 连接建立、断开、心跳等连接维护动作不作为业务记录，不影响后台处理。
- 推送给用户的内容经过脱敏处理，不暴露原始模型输出、工具结果、密钥或文件路径。
- 使用 SSE 还是 WebSocket 由后台配置决定，用户不能自行指定。
- 已完成的对话内容以历史消息为准，不依赖实时推送拼凑。
- 浏览器不读取隐藏消息；消息引用必须同时匹配当前用户、智能体、会话、请求、运行、消息类型和 Tool 调用，失败只显示安全状态。
- 持久化 event 不复制可从消息恢复的正文、Tool 参数或结果；进行中 delta 保持 live-only。
- 浏览器不使用独立计时器再次逐字播放已经接收的累计答案，也不为待定正文到最终答案的接管增加位置或透明度动画。
