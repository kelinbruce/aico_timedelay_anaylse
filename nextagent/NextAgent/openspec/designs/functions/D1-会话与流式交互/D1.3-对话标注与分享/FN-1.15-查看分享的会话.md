# FN-1.15 查看分享的会话

> 能力域 D1 会话与流式交互 · 子域 [D1.3 对话标注与分享](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.8](../../../features/D1-会话与流式交互/D1.3-对话标注与分享/F-1.8-分享对话.md) |
| spec | `conversation-share` |
| 接口 | `GET /api/v1/shares/:shareId/conversation` |

## 描述

通过分享链接只读查看会话内容，查看者无需登录创建者账号。

## 前置条件

- 分享链接有效且未过期。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| shareId | 是 | 分享标识 |

## 输出

```json
{
  "sessionId": "sess_123",
  "messages": [
    {
      "messageId": "msg_1",
      "role": "USER",
      "content": "分析小区掉话率升高原因",
      "contentType": "TEXT",
      "visible": true,
      "createdAt": 1719878400000
    }
  ],
  "createdAt": 1719878400000
}
```

## 处理过程

1. 校验分享链接是否有效且未过期。
2. 返回分享绑定的会话消息，只读。
3. 可通过请求头传入查看者操作信息。

## 结果

- 正常：返回会话消息，只读。
- 分享过期：返回 403 或 410。
- 分享不存在：返回 404。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 分享查看时延 | <= 1,000 ms | 建议评审值 | 建议补充 |
