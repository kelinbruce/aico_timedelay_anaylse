# 模块不可测节点总表

| 节点 | 当前状态 | 原因 | 本 change 处理 |
|---|---|---|---|
| 真实 AICO Service consumer | PLANNED | 当前没有可执行 consumer artifact | 保留 deferred entry；不使用 provider-side surface 冒充 |
| 尚未闭合的发布级联合流程 | PLANNED | artifact 或稳定行为不完整 | 记录 owner 和重新准入条件 |
| 性能 SLO | EXCLUDED | `ts-performance-test-gate` 已由独立 performance owner 定义并形成单独 verdict | 保留独立 coverage entry；不复制为 `TC-SI-*` 结果 |
| 容量上限 | EXCLUDED | 没有稳定容量边界 | 不生成 skip/占位 case |
| 集群部署与一致性 | EXCLUDED | 当前候选包/规格不定义集群系统 | 不计入 122 |
| remote Agent/AgentLink | EXCLUDED | 无稳定产品契约和真实入口 | 不计入 122 |
| 厂商真实远端环境 | PLANNED | 本 change 只拥有 loopback 合规边界 | loopback 验证协议组合；不声明厂商互认证 |

deferred 节点不会获得 `TC-SI-001..122` case id，不进入执行结果，也不改变当前 verdict。已有独立 gate owner 的范围只有在后续 OpenSpec 明确组合 verdict 时才准入；其他范围只有稳定 OpenSpec、可执行 artifact 和真实可观察入口同时具备后，才通过新的 change 准入。
