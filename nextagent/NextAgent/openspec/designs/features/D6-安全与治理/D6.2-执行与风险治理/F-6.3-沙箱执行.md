## 描述

动态命令、脚本和模型生成代码必须通过沙箱网关执行，默认拒绝，控制超时、输出和环境；本地执行不会为模拟只读边界而改变调用方资源的权限。

## 边界

- 沙箱控制超时、标准输出/错误、环境变量和工作目录。
- 沙箱不可用时默认拒绝执行。
- LOCAL 模式保持受信 root layout 与入口约束，但只提供 best-effort 隔离；强文件系统隔离由 REMOTE/PaaS 的容器或 Pod 提供。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |

| 命令执行超时 | 120,000 ms 默认，300,000 ms 硬上限 | 建议评审值 | 建议补充 |
| 标准输出/错误最大大小 | 1 MiB/流 | 建议评审值 | 建议补充 |
| 沙箱绕过允许次数 | 0 | 已定义 | 安全红线 |
