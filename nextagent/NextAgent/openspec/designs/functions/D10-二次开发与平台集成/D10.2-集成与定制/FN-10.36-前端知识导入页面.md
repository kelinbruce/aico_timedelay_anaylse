# FN-10.36 前端知识导入页面

> 能力域 D10 二次开发与平台集成 · 子域 [D10.2 集成与定制](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 主规格 | `agent-web-knowledge-import` |
| 接口 | Agent Web 知识导入页面 PIU 渲染契约（浏览器内部） |

## 描述

系统在 Immersive 和 Collaborative/PIU 宿主中提供知识导入页面，通过 `PiuRenderer` 渲染 `MCSemanticPIU` 的 `loadDataSet` 方法。该页面不依赖投诉 probe 探针，在非 local 宿主下始终可见。

## 前置条件

- Agent Web 宿主已提供可用的主内容容器和当前主题。
- `window.Prel` 可用于 PIU 渲染（不可用时显示占位符）。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| PIU 声明 | 是 | `{ piuName: "MCSemanticPIU", piuVersion: "1.0.0", renderFunc: "loadDataSet" }` |
| 宿主主题 | 是 | 浅色/暗色主题 |

## 输出

渲染 `MCSemanticPIU / loadDataSet` 的知识导入内容。

## 处理过程

1. `KnowledgeImportView` 通过 `PiuRenderer` 声明 `MCSemanticPIU / loadDataSet`，按当前主题渲染。
2. `KnowledgeImportPage` 以共享 `PageHeader`（标题 `knowledge.importTitle`）包裹 `KnowledgeImportView`。
3. Immersive 左布局通过 Sidebar NavButton + 路由 `/knowledge-import` 呈现。
4. Immersive 右布局通过顶部栏 Tooltip Button + 路由面板视图呈现。
5. Collaborative/PIU 通过 MoreMenuButton → `expandPanelStore.setView` 呈现。
6. 入口位置在记忆管理之后、投诉历史之前，三宿主一致。

## 结果

- 正常：PIU 渲染知识导入内容。
- `window.Prel` 不可用：显示占位符，不抛错。
- Local 宿主：不渲染入口。

| 入口位置 | 记忆管理之后、投诉历史之前 | `agent-web-knowledge-import`：`知识导入入口在多宿主下的可见性与呈现` |
