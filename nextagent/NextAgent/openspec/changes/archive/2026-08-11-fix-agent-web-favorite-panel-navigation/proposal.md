## Why

使用 Local 或 Immersive 页面回顾收藏对话时，收藏入口当前会把左侧最近会话列表替换为收藏列表。用户随后点击会话、记忆管理或投诉历史等入口时，收藏状态与主内容状态可能同时保持激活，导致导航反馈与实际显示内容不一致，也使历史会话与收藏内容相互覆盖。

收藏是用于回顾关键问答的独立内容视图，不应改变最近会话导航的可见性。现在需要统一收藏内容的显示位置和菜单选择语义，使用户能稳定判断当前内容，同时保留随时切换历史会话的能力。

同一个 session 可以包含多个被收藏的 turn。若每个 turn 都占用一张同等层级的外部卡片，同一会话的标题和辅助信息会重复出现，收藏较多时主内容区域难以快速浏览。因此，收藏内容还需要在不合并收藏事实、不丢失单条定位和取消能力的前提下，按 session 收敛为更紧凑的展示分组。

现有主内容收藏面板仍沿用通用列表样式，缺少返回入口、内容过滤和会话正文回顾能力。用户只能看到收藏问题摘要，无法在收藏页内判断完整问答上下文；取消收藏也缺少二次确认。需要把收藏面板收敛为与主页主题一致的专用内容页，在保持收藏响应结构不变的前提下由接口执行过滤，并复用既有会话读取能力补齐正文展示。

**规范上下文：**

- 适用宿主：Local，以及 Immersive 的 LEFT、RIGHT 两种布局。
- Collaborative/PIU 的沉浸式首页卡片已在“更多”菜单提供收藏入口；本 change 让该入口与记忆管理一致，在 PIU 左侧扩展内容容器复用同一收藏内容，不新增 PIU hash 路由。
- “收藏内容视图”指在页面主内容区域中展示按 session 分组的收藏 turn 列表；它不包含左侧最近会话列表或会话搜索对话框。

## 目标与非目标（Goals / Non-Goals）

**目标：**

- 用户点击收藏入口后，在主内容区域看到按 session 分组的分页收藏内容；面板占满宿主容器扣除统一 padding 后的宽度，以显式分页器每页默认展示 15 个 session，全部收起时不出现列表滚动条；左侧最近会话列表保持可见且内容不被替换。
- 收藏内容提供“收藏回答”和“收藏问题”两个 Tab；Tab 与下方过滤内容保持清晰间距，切换 Tab 后以相同的会话分组、过滤、展开正文、分页和取消收藏布局展示对应类型的收藏。
- 收藏主内容提供固定高度的标题栏和返回操作；返回目标是进入收藏前的 session 路径，未选中 session 时返回新会话路径。
- 收藏主内容提供关键词搜索与精确到秒的起止时间过滤，并允许清除关键词、分别快捷清除任一日期输入或重置日期范围。
- 同一 session 的收藏 turn 只占用一张四边边框完整可见的会话分组卡片，相邻会话卡片保持 8px 间距；默认只显示自适应容器且最大 56px 高的会话摘要，展开时自动将目标会话和正文起始位置带入收藏内容视口，随后以压缩间距显示该 session 中各收藏 turn 的用户问题与智能体回答正文；智能体正文复用实际对话卡片的 Markdown 渲染并按内容自然调整高度，单行内容不产生额外空白行。
- Local 与 Immersive 的 LEFT、RIGHT 布局对收藏入口、收藏空态、加载失败和收藏项选择提供一致的可观察行为。
- Collaborative/PIU 从“更多”菜单在 PIU 左侧扩展内容容器打开收藏，复用与记忆管理相同的容器以及收藏面板的过滤、分组、展开、取消收藏和显式分页行为。
- 收藏、会话、记忆管理和投诉历史等主内容入口只反映当前选中的内容视图，不出现多个互相冲突的激活状态。
- 用户选择收藏 turn 后返回对话视图，打开所属会话并定位到对应回合。
- 用户可直接在会话分组的 turn 行上取消收藏；成功后只更新对应分组且不打开会话，失败时保留 turn 行并允许重试。
- 用户取消收藏前看到确认提示；取消确认不会改变收藏，确认后才提交取消写入。
- 收藏标题栏、过滤区、会话卡片和展开正文使用主页统一的浅色/暗色主题变量，不形成独立硬编码配色。
- 收藏内容使用独立 hash URL；用户可直接打开该 URL，并可通过浏览器前进、后退恢复收藏主内容。记忆管理的 `#/memory` 由既有 `add-ts-long-memory-manage` change 负责，本 change 只保证两个入口在共享 Shell 中互斥协作。
- 搜索、设置和帮助等临时交互不改变当前主内容视图。

**非目标：**

- 不改变收藏事实、排序、分页、数量上限、scope 隔离或标注写入语义。
- 不把同一 session 的多个收藏 turn 合并为一条收藏事实，也不新增 session 级收藏语义或全量收藏数量统计。
- 不修改 `GET /api/v1/favorites` 的响应 shape、收藏事实、授权或错误包装契约；请求只增加本 change 所需的可选过滤参数和收藏类型参数。
- 不为投诉历史、最近历史或其他临时交互新增专用 URL，不把主内容选择写入 `localStorage` 或 `sessionStorage`。
- 不为 Collaborative/PIU 新增收藏专用 URL、平行收藏查询状态或新的导航 authority；PIU 只消费主线已有“更多 → 收藏”入口和既有左侧扩展内容容器。
- 不改变会话搜索对话框、PIU History Popover、记忆管理、投诉历史或自定义 operator 的功能边界。

## What Changes

- 修改 Local 与 Immersive 的收藏入口行为：入口选择收藏内容视图，不再切换或替换最近会话列表。
- 修改收藏列表展示行为：Local、Immersive LEFT、Immersive RIGHT 和 Collaborative 左侧扩展容器使用一致的满宽 session 分组卡片并保持 8px 卡片间距；完整有界收藏窗口先按 session 合并，再以每页 15 个 session 的显式分页器展示；展开会话时自动滚动到目标会话顶部，受底部滚动边界限制时至少保证正文起始位置可见；展开正文压缩问答间距，智能体正文复用共享 Markdown 渲染并按内容自然调整高度，且不渲染末尾换行形成的空白行。
- 增加收藏内容标题栏和返回操作，保留进入收藏前的 session 或新会话路由作为返回目标。
- 增加关键词搜索和日期时间范围过滤；`GET /api/v1/favorites` 接收可选 `keyword`、`favoritedFrom` 和 `favoritedTo`，服务端在 owner/agent scope 内先过滤再分页，浏览器不再为过滤拉取全部收藏后自行筛选。
- 增加回答/问题收藏切换；`GET /api/v1/favorites` 接收可选 `favoriteType=ANSWER|QUESTION`，缺省时保持回答收藏语义，并复用既有问题收藏查询能力返回同形结果。
- 将会话分组调整为默认 56px 摘要卡片；展开时复用既有会话读取契约展示收藏 turn 对应的用户问题与智能体回答正文，并在收藏图标上提供取消确认。
- 保持收藏事实为 turn 粒度；浏览器读取服务端过滤后的完整有界收藏窗口，先按 session 合并，再通过显式分页器切换当前可见分组，不保留滚动触发的追加分页状态。
- 修改主内容菜单选择行为：收藏、对话、记忆管理和投诉历史由单一当前选择决定可见内容与激活反馈；临时对话框和帮助操作保持独立。
- 为收藏内容增加 `#/favorites`；Local 与 Immersive 在各自宿主基地址下复用相同 hash 路径，直达、刷新和浏览器前进/后退由 URL 恢复收藏主内容与激活反馈。共享 Shell 同时消费既有长期记忆 change 定义的 `#/memory`，但记忆路由行为不由本 Function 重复定义。
- 保留收藏项选择后的既有会话恢复与回合定位结果。
- 使用共享主题 CSS 变量统一收藏页面的浅色与暗色投影。
- 接通 Collaborative/PIU 已有“更多 → 收藏”入口，在与记忆管理相同的 PIU 左侧扩展内容容器显示共享收藏面板；关闭或打开收藏会话后收起该容器并保留 PIU 的 URL 规则。

## Feature 影响（Features）

### 新增 Feature

无。

### 修改的 Feature

- `F-1.7 标注对话`：收藏回顾从替换最近会话列表调整为主内容区域中的独立 session 分组视图；用户在保留会话导航的同时查看并打开收藏 turn。

### 移除的 Feature

无。

### 新增 Function

无。

### 修改的 Function

- `FN-1.12 标注对话` → `specs/conversation-annotation-controls/spec.md`
  - 功能边界：既有前端标注图标、状态恢复、乐观更新和失败反馈行为保持不变；从同时包含收藏列表导航的 legacy Requirement 中原子拆分。

## 影响范围（Impact）

- 用户：收藏列表的位置和菜单反馈发生变化；收藏页增加返回、搜索、日期过滤和正文回顾；同一会话的收藏 turn 收敛到一张可展开的会话分组卡片，既有单条取消收藏、排序和打开目标保持不变。
- 外部系统与公共 API：`GET /api/v1/favorites` 新增三个可选查询参数；响应、鉴权、配置和运维不变。
- 前端：Local 与 Immersive shell、Collaborative/PIU 首页卡片、收藏列表组件、侧边栏交互和对应的多布局测试受到影响。
- 验证：需要覆盖收藏视图不替换最近会话、收藏 URL 直达/刷新/浏览器历史恢复、与记忆管理入口的互斥集成、同 session 分组与同标题不同 session 隔离、每页默认 15 个 session 的显式分页、满宽卡片与 8px 间距、全部收起时无滚动条、展开会话自动进入视口、展开后智能体 Markdown 自然高度且单行回答无额外空白、组内取消收藏、各主内容入口不产生冲突激活状态、加载失败可重试，以及收藏项恢复目标会话。
