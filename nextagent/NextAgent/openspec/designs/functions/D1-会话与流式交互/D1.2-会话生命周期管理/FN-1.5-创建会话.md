# FN-1.5 创建会话

> 能力域 D1 会话与流式交互 · 子域 [D1.2 会话生命周期管理](.) · 返回 [功能树](../../index.md)

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-1.3](../../../features/D1-会话与流式交互/D1.2-会话生命周期管理/F-1.3-管理会话.md) |
| spec | `ts-minimal-agent-kernel` |
| 接口 | `POST /api/v1/sessions` |

## 描述

创建一个空的会话，返回会话标识和最小元数据。

## 前置条件

- 用户已登录。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| locale | 否 | 语言偏好，可省略 |

## 输出

```json
{
  "sessionId": "sess_123",
  "displayTitle": "Untitled session",
  "lastActivityAt": 1719878400000
}
```

## 处理过程

1. 系统按当前用户归属和智能体归属创建会话。
2. 返回会话标识、默认标题和最后活动时间。

## 结果

- 正常：创建成功，返回会话标识。
- 权限不足：安全拒绝。

## 规格

| 规格项 | 规格值 | 状态 | 来源 |
|---|---|---|---|
| 单用户最大会话数 | 5,000 | 建议评审值 | 建议补充 |
| 会话创建频率 | 60 个/小时/用户 | 建议评审值 | 建议补充 |
