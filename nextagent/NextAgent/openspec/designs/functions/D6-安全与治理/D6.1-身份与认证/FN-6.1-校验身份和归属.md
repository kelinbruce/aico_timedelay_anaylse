# FN-6.1 校验身份和归属

| 项 | 值 |
|---|---|
| 覆盖特性 | [F-6.1](../../../features/D6-安全与治理/D6.1-身份与认证/F-6.1-双层身份隔离.md) |
| spec | `ts-minimal-agent-kernel`、`ts-core-contracts` |
| 接口 | 系统内部，数据访问校验 |

## 描述

系统在数据访问时校验用户归属和智能体归属，拒绝越权访问。

## 前置条件

- 用户已通过认证。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 身份信息 | 是 | 用户和智能体归属 |
| 访问目标 | 是 | 要访问的数据 |

## 输出

校验通过或安全拒绝。

## 处理过程

1. 系统校验用户归属。
2. 系统校验智能体归属。
3. 越权访问安全拒绝，不暴露目标是否存在。

## 结果

- 通过：允许访问。
- 越权：安全拒绝，不暴露目标是否存在。

| 跨智能体数据泄露容忍次数 | 0 | 已定义 | 安全红线 |
